# 베스페라 호텔 제출 영상 스토리보드

- 형식: 1280×720, 2분 30초, 고정된 실제 플레이 화면 기반 자동 재생
- 움직임: 장면 전환, 가상 커서, 클릭 파동과 강조선만 사용하며 배경 플레이 화면에는 확대·이동을 적용하지 않는다.
- 목표: 설명보다 의사결정의 흐름을 먼저 보여준다.
- 범위: 현재 빌드에 구현된 두 번의 영업, 운영 수첩, 시설 선택, 예약 수락/거절, 규칙 해금, 최종 평가
- 제외: 객실 내구도, 청결, 연박은 후속 설계이므로 제출 영상에 넣지 않는다.

## 조작

- `Space`: 재생/정지
- `←`, `→`: 5초 이동
- `R`: 처음부터
- `F`: 전체 화면
- `2분 30초 영상 저장`: 캔버스 애니메이션을 WebM으로 실시간 녹화해 저장
