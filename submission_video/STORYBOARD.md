# 베스페라 호텔 제출 영상 스토리보드

- 형식: 1280×720, 2분 30초, 고정된 실제 플레이 화면 기반 자동 재생
- 움직임: 장면 전환, 가상 커서, 클릭 파동과 강조선만 사용한다. 배경 플레이 화면에는 확대·이동을 적용하지 않는다.
- 목표: 플레이 장면은 **개장 전 초청 영업**이라는 호텔 세계관 용어로 통일하고, 00:06의 진행 안내에서만 5회 구성이 정식 성장 속도가 아님을 명확히 전달한다.
- 범위: 무제한 튜토리얼, 5회의 시간제 영업, N·R·SR·SSR 등급, 평판별 제안 확률, 손님 수용·거절, 객실 수 기반 응대 한도와 연박 객실도, 숨은 선호 열람, 동관 증축과 시설·인테리어 계약, 종족 시너지·상극, 연박과 객실 상태, SSR 특별 초청, 최종 결과
- 용어: 만나지 않은 종족·등급의 공개 규정 전체(필수 숙박 조건+공통 선호)는 `미열람 규칙`, 처음 숙박한 종족×등급 조합이 정산 뒤 공개하는 추가 점수 조건은 `숨은 선호`로 표기한다.

## 강조선과 커서

- 장면별 좌표는 `box_audit/targets.json`에 1280×720 기준으로 기록한다.
- 실제 새 에셋과 좌표가 모두 존재하는 장면에만 강조선과 커서를 표시한다.
- 좌표 파일이 비어 있거나 특정 장면 항목이 없으면 해당 장면은 고정 배경과 자막만 사용한다.
- `box_audit/scene-*.png`에서 강조선이 실제 UI 요소를 정확히 감싸는지 확인한 뒤 최종 영상을 녹화한다.

## 조작

- `Space`: 재생/정지
- `←`, `→`: 5초 이동
- `R`: 처음부터
- `F`: 전체 화면
- `개장 전 초청 영업 영상 저장`: 캔버스 애니메이션을 2분 30초 WebM으로 실시간 녹화
