# v2 코어 만족도·평판 전수조사 보고서

## 결론

유효 배치, 내부 만족도, 후기, 평판 사이의 인과 연결을 구현하고 브라우저 상태에서 다시 전수 조사했다.

- 하드 제약을 모두 지킨 유효 배치는 숙박 성립만 보장하며 고정 평판을 주지 않는다.
- 선호·시너지·상극·공개 불호·호텔 격차 관용이 손님별 내부 만족도를 만든다.
- 만족도가 음수면 `아쉬움`, 등급별 호평 기준 미만이면 `무난`, 기준 이상이면 `호평` 후기가 된다.
- `무난`은 평판 0이다. `호평`과 `아쉬움`만 N/R/SR/SSR별 1/2/4/7의 영향력을 가진다.
- 결산 화면에는 정성 후기와 평판 영향만 표시하고 내부 만족도 수치는 노출하지 않는다.

첫 영업의 같은 네 손님을 대상으로 한 612개 유효 배치에서 선호 점수와 내부 만족도는 0~26, 평판 변화는 0~+4로 갈렸다. 최저 결과는 네 손님 모두 `무난`이며 평판 변화가 정확히 0이다. 이전의 “유효 배치만 하면 항상 +4” 문제는 해소됐다.

## 조사 범위

- 실행 시드: `20260819`
- 데이터 스키마: `3`
- 감사 산출물 스키마: `2`
- 실제 브라우저에서 튜토리얼부터 5단계 최종 화면까지 두 경로 플레이
- 일반 성장 경로: 증축 우선, 가능한 손님을 적극 수용
- 최저점 경로: 각 단계에서 평가 점수가 가장 낮은 유효 결과를 선택하고 공사를 건너뜀
- 각 실제 도달 상태에서 모든 수용·거절 부분집합과 가능한 일대일 객실 배치를 열거
- 하드 제약을 만족한 결과마다 선호 점수, 내부 만족도, 후기 반응, 평판 변화, 평가와 수입을 기록

두 경로를 합쳐 후보 배치 509,858개, 유효 배치 59,055개, 서로 다른 결과 변형 16,257개를 검사했다. 이 수치는 두 실제 도달 경로 안의 단계별 전수 열거이며, 모든 이전 배치와 모든 공사 선택을 곱한 캠페인 전체 상태 공간은 아니다.

3단계부터 선호 점수와 내부 만족도 범위가 달라진다. 호텔 평판 단계가 손님 등급보다 높을 때의 위신 보너스와 공개 불호의 활성·무시 여부가 내부 만족도에만 반영되기 때문이다. 팁은 계속 플레이어가 배치 중 확인한 선호 점수를 기준으로 계산된다.

| 단계 | 영업 완료 | 좋은 운영 | 훌륭한 운영 |
| ---: | ---: | ---: | ---: |
| 1 | 3.27% | 52.61% | 44.12% |
| 2 | 4.65% | 30.81% | 64.53% |
| 3 | 0.04% | 11.97% | 87.99% |
| 4 | 2.90% | 30.06% | 67.04% |
| 5 | 0% | 3.76% | 96.24% |

평가는 고정 수입 합산식 대신 손님별 `만족도 / 해당 등급 호평 기준`의 평균 달성률로 정규화됐다. 다만 일반 성장 경로의 3·5단계 최고 평가 비율은 여전히 높아, 목표 난이도에 따라 추가 밸런스 판단이 필요하다.

## 두 실제 경로 비교

| 경로 | 1일차 평판 | 최종 평판 | 최종 골드 | 관찰한 등급 |
| --- | ---: | ---: | ---: | --- |
| 일반 성장 | 3 | 18 | 140G | N/R/SR/SSR |
| 최저점·무공사 | 0 | -27 | 88G | N/R/SR/SSR |

최저점 경로의 첫 영업은 선호 점수 0, 내부 만족도 0, 네 건의 `무난` 후기, 평판 0으로 끝난다. 이후에는 상극과 불만족 후기, 거절 손실이 겹쳐 평판이 -27까지 내려간다. 반대로 일반 경로도 매번 자동으로 평판을 얻지는 않는다. 3일차는 N 손님 네 명의 호평을 SR 손님 한 명의 아쉬움(-4)이 상쇄해 평판 변화가 0이다.

등급별 영향력 차이도 실제 결과에 반영된다.

- N 호평·아쉬움: 평판 ±1
- R 호평·아쉬움: 평판 ±2
- SR 호평·아쉬움: 평판 ±4
- SSR 호평·아쉬움: 평판 ±7

## 결산 후기 검증

5개 영업을 실제 브라우저로 진행하며 각 결산에서 다음을 확인했다.

- 수용 손님 수와 후기 카드 수가 일치한다.
- 각 카드의 `호평/무난/아쉬움`이 내부 만족도 구간과 일치한다.
- 후기별 평판 영향 합이 정산의 후기 평판 합계와 일치한다.
- `무난` 후기의 평판 영향은 항상 0이다.
- 후기 영역의 HTML에는 내부 필드명이나 정확한 만족도 숫자가 노출되지 않는다.

대표 경로의 후기 분포는 1일차 `호평 3·무난 1`, 3일차 `호평 4·아쉬움 1`, 4일차 `호평 3·무난 2`였다. 따라서 정산 화면은 단순 점수표가 아니라 어떤 손님이 왜 평판에 영향을 줬는지 확인하는 피드백 장치로 작동한다.

## 남은 설계 판단

구현 검증과 별개로 다음은 플레이 목표에 따라 사용자가 결정해야 한다.

1. 3·5단계의 최고 평가 비율을 현재 수준으로 둘지 더 엄격하게 조정할지.
2. 저평판에서도 3단계 SR 보장과 5단계 SSR 특별 초청을 유지할지, 조건부 초청으로 바꿀지.
3. 후기 문체를 현재의 짧은 원인 요약으로 유지할지, 종족·인물별 어조를 추가할지.

이 세 항목은 시스템 오류가 아니라 난이도·서사 톤 선택이므로 자동 확정하지 않았다.
