# 운영 수첩과 공유 지식 설계

- 상태: `DRAFT`
- 적용 범위: 정식판 운영 수첩의 정보 구조, 발견 상태, 모드 공유와 스포일러 경계
- 비적용 범위: 현재 v2 UI의 구현 완료 범위를 자동으로 확장하지 않음

운영 수첩이라는 명칭을 유지한다. 기능적으로는 현재 영업의 규칙을 빠르게 확인하는 도구이자 종족·시설·아이템·손님·시너지·사건 기록을 연결하는 영구 지식 체계다.

## 1. 설계 목표

- 손님 카드에 공통 규칙을 반복하지 않고 수첩에서 규칙 상속을 확인한다.
- 캠페인과 무한 영업에서 얻은 기계적 지식을 하나의 프로필에 축적한다.
- 현재 런에 활성화된 규칙과 과거에 발견한 다른 변화형을 구분한다.
- 시설과 종족, 시너지와 사건을 양방향 링크로 연결한다.
- 숨은 요소의 존재와 총개수를 발견 전에 누설하지 않는다.
- 정답 배치와 검산 최고점을 제공하지 않고 플레이어가 확인한 사실만 정리한다.

## 2. 화면 구조

| 구역 | 내용 |
| --- | --- |
| 이번 영업 | 현재 손님·시설로 활성화된 필수 조건, 충돌과 시설 범위 |
| 호텔 규정 | 객실, 층, 인접, 등급, 연박, 정비와 감사 규칙 |
| 종족·직업 | 종족·출신·계통·문화·신앙·직업, 평판 단계와 운영 방향 |
| 시설·아이템 | 해금 가능한 시설, 효과, 비용, 위험, 획득 경로와 대응법 |
| 전시품 | 공용·종족·관계 후보군, 제안·획득·발동 기록과 현재 런의 누적 패시브 |
| 시너지·상극 | 참가 집단, 발동 조건, 기본형과 발견한 변화형 |
| 손님 기록 | 조우·수용·투숙·숨은 선호·재방문과 대표 기록 |
| 인물·사건 | 관계 인물 장면, 종족 사건과 현재 런에서 확인한 결과 |
| 업적·기록 | 특이한 운영, 엔딩, 무한 영업 시즌과 최고 기록 |

`이번 영업`은 빠른 운영 도구이고 나머지는 장기 기록이다. 수첩을 열면 현재 화면과 선택 손님을 보존하고, 닫으면 같은 상태로 복귀한다. 시간 제한 영업에서는 현재 v2와 같이 수첩 열람 중 타이머를 멈춘다.

## 3. 발견 단계

| 상태 | 공개 내용 |
| --- | --- |
| 미조우 | 일반 공개 항목의 분류와 윤곽만 표시 가능 |
| 단서 발견 | 명칭 또는 대략적인 해금 방향 표시 |
| 해금 | 정확한 효과, 비용, 위험과 획득 조건 공개 |
| 사용·투숙 확인 | 실제 결과, 관련 손님과 시너지 기록 |
| 완전 발견 | 공개 가능한 모든 변화형과 대응법 확인 |

공개 가능한 공용 시설은 윤곽과 넓은 해금 힌트를 보여줄 수 있다. 종족 특화 시설은 해당 종족의 첫 조우 뒤, 분기 전용 시설은 관련 시나리오가 열린 뒤 목록에 나타난다.

숨은 적대 요소와 최고난도 경로 전용 항목은 발견 전까지 항목, 빈 슬롯, 미발견 개수와 완성률에서 모두 제외한다.

## 4. 시설·아이템 항목

시설 항목은 다음 필드를 가진다.

- 명칭, 종류, 희귀도와 발견 상태
- 해금 출처와 현재 모드의 획득 가능 여부
- 건설·구매비, 유지비와 철거·정지 조건
- 차지하는 객실·시설 슬롯
- 작동 층·인접·거리·동 범위
- 주 보상과 보조 보상
- 영향을 받는 종족·계통·직업
- 소프트 감점과 하드 제약
- 충돌하는 다른 시설
- 중재·완화 시설과 대가
- 관련 종족 시나리오와 협약 방향
- 발견한 시너지 변화형과 실제 사용 기록

아이템은 소유 위치, 사용 횟수, 대상 객실·시설·손님, 일시·영구 여부와 부작용을 같은 원칙으로 기록한다.

`존재를 알고 있음`, `현재 런에서 해금됨`, `현재 소유함`, `현재 작동 중`을 별도 상태로 저장한다.

전시품은 일반 아이템과 달리 호텔 평면에 배치하지 않는다. 열린 후보군에서 무작위로 제안된 항목 중 하나를 선택하면 현재 런이 끝날 때까지 자동 발동하며, 세부 규칙은 `28_EXHIBITION_RELIC_SYSTEM.md`를 따른다.

## 5. 종족·직업 항목

- 종족 공통 필수 조건과 공개 선호
- 자연 출생·전환·선천·각성 등 확인된 출신과 관련 문화 관계
- 계통·문화·신앙·직업 풀
- 객실 청결·내구와 시설 영향
- 호텔·종족 평판 단계별 공개 해금
- 일반·특화·협약 시설
- 선호·불호 시설과 하드 제약
- 다른 종족과의 기본 관계
- 현재 캠페인의 전문화·중재·화합 방향
- 기본 시너지와 현재 활성 변화형
- 관련 손님, 관계 인물과 확인한 사건

종족 페이지에서 모든 관련 시설·손님·시너지로 이동할 수 있고, 각 시설·시너지 페이지에서도 영향을 받는 종족으로 돌아갈 수 있어야 한다.

출신 정보는 종족의 신체 규칙과 분리한다. 출신이 점수나 관계에 영향을 줄 때만 열람된 근거와 효과를 표시하고, 자연 출생·전환 출신 자체를 보편적인 선호·불호 또는 숨은 감점으로 만들지 않는다. 마녀의 `각성`은 감염 출신으로 분류하지 않으며 자발적 구조·공동체 양육·강제 모집의 맥락은 관련 인물 사건이 열리기 전까지 수첩에서 단정하지 않는다.

## 6. 시너지·상극 항목

- 참가 종족·출신·계통·문화·신앙·직업
- 인원, 같은 층, 인접, 거리와 시설 조건
- 기본 효과와 비용
- 현재 런에서 활성화된 효과
- 강화·약화·악화·반전·분화·신규 발견 상태
- 변경을 일으킨 확인된 시나리오 선택
- 실패 시 감점, 유지비와 객실 영향
- 발견한 다른 런의 변화형

프로필은 발견한 모든 변화형을 기록할 수 있지만 현재 런에 적용되는 하나에는 `현재 활성` 표식을 붙인다. 발견하지 않은 분기 결과를 미리 보여주지 않는다.

## 7. 손님과 숨은 선호

- 조우, 수용, 투숙, 완전 발견 상태를 분리한다.
- 공개 개인 선호는 첫 신청부터 기록한다.
- 종족·등급 공개 규정은 첫 신청에서 열람한다.
- 종족×등급 숨은 선호는 실제 투숙 결산 뒤 기록한다.
- 숨은 선호는 양수 선택 점수만 사용하고 숨은 필수·감점·배정 불가를 만들지 않는다.
- 방문 횟수, 직전·최고 만족도, 발견한 대표 기록을 보존한다.

## 8. 검색과 운영 연결

- 이름, 종족, 직업, 시설 종류와 효과 축 검색
- 층·인접·거리·시설 범위 필터
- 현재 활성 규칙만 보기
- 최근 해금·변경 내역
- 관심 항목 고정
- 시설 두 개의 비용·범위·위험 비교
- 배치 불가 사유에서 관련 규정으로 이동
- 시너지 원인 표시에서 발동 조건으로 이동
- 종족 페이지와 시설·손님·시너지의 양방향 링크

수첩은 규칙과 관찰 기록을 제공하지만 추천 최적 배치, 검산 최고점과 자동 정답을 표시하지 않는다.

## 9. 모드 공유와 세이브 경계

### 공용 프로필에 저장

- 수첩 항목별 발견 단계
- 일반 규정과 숨은 선호
- 시설·아이템의 존재와 확인한 효과
- 종족·직업과 시너지 변화형
- 손님 조우·투숙 기록
- 업적, 장식, 칭호와 최고 기록
- 전시품 후보군 자격과 제안·획득·효과 발동 도감 기록

### 캠페인·무한 영업 세이브에 분리

- 현재 획득 가능·소유·작동 시설과 아이템
- 현재 런에서 보유한 전시품, 대기 중인 무작위 후보와 발동 횟수
- 골드, 호텔·종족 평판
- 호텔 구조, 객실 상태와 연박 손님
- 종족 협약과 현재 활성 시너지
- 플레이어 성별, 관계 인물 성별 프리셋과 역할별 표현 변형. 마녀 역할은 여성 고정
- 관계 인물 관계, 사건, 조사와 엔딩 상태
- 무한 영업 시즌, 감사 목표와 런 명성

공유 지식은 다른 모드의 수치나 자원을 직접 올리지 않는다. 캠페인에서 확인한 종족 변형과 전시품 후보군 자격은 무한 영업 생성 풀을 열 수 있고, 무한 영업에서 발견한 일반 손님 선호는 캠페인에서도 참고할 수 있다. 실제로 선택한 전시품 패시브는 현재 런에서만 작동하고 다음 런으로 넘어가지 않는다.

마감 서명을 남긴 경로는 일반 투숙 기록으로 저장한다. 마감 대화에서 아침 장부 재열람을 선택한 경로는 직접 관찰한 종족×등급 숨은 선호만 지배인의 기억으로 수첩에 남긴다. 해당 경로의 투숙 횟수, 관계 인물의 호감도, 대화 선택, 조사 증거와 사건 완료는 실제 기록으로 남기지 않는다. 플레이어 화면은 이를 `예지로 관찰`처럼 명명하지 않고, 재열람 뒤에도 정보가 남아 있는 현상 자체를 단서로 사용한다.

관계 인물의 공통 역할 ID와 선택한 성별 표현 ID를 분리해 저장한다. 수첩의 기계적 종족 지식은 성별 변형과 무관하게 공유하지만, 초상·개인 장면·회상과 관계 엔딩 기록은 해당 캠페인에서 선택한 표현만 보여 준다.

정식판 일반 손님 기록은 선택적 성별 정보를 보존할 수 있다. 성별만으로 수첩 규칙·만족도·평판에 공통 보정을 만들지 않으며, 개별 손님·문화·사건에 인과가 있어 명시적으로 작성된 선호·불호와 조건만 이를 참조한다. 플레이어 성별을 참조하는 개별 반응도 해당 손님 항목에 원인과 함께 기록한다. 몽마의 성별, 성적 지향과 꿈·정기 적합성은 서로 다른 정보로 분리한다.

## 10. 스포일러 경계

- 발견 전 숨은 요소는 검색 결과, 빈 슬롯, 항목 개수와 완성률에서 제외한다.
- 캠페인 전용 사건 문구와 증거는 무한 영업의 일반 항목에 노출하지 않는다.
- 숨은 요소를 발견한 뒤에만 관련 규칙·시설·손님 항목을 생성한다.
- 다른 런에서 발견한 기계적 효과는 공유할 수 있지만 현재 캠페인에서 발생하지 않은 사건을 발생한 것으로 표시하지 않는다.
- 플레이어 대상 완성률은 공개 가능한 항목만 분모로 사용한다.

## 11. 보상 원칙

수첩 완성률 보상은 장식, 칭호, 기록 이미지와 도트 캐릭터 같은 수집 요소를 우선한다. 종족 우호도·관계 인물 신뢰도·호감도로 열리는 전시품은 도감에 포함되는 런별 선택 보상이며, 도감 완성률만으로 강한 수치 보상을 추가 지급하지 않는다. 전시품의 효과도 한 런의 제안 횟수와 효과군 상한으로 누적을 통제한다.

발견 상태, 프로필 지식, 모드별 가용성과 현재 소유 상태를 하나의 잠금 값으로 합치지 않는다.

## 13. 검증 조건

- 같은 프로필을 사용하는 두 모드에서 일반 발견 상태가 일치한다.
- 모드별 골드·평판·시설 소유와 관계 상태는 공유되지 않는다.
- 전시품 도감과 후보군 자격은 공유되지만 현재 런의 보유 전시품과 대기 후보는 공유되지 않는다.
- 발견하지 않은 숨은 항목이 검색·완성률·빈 슬롯에 나타나지 않는다.
- 현재 활성 시너지와 과거에 발견한 변화형을 혼동하지 않는다.
- 시설의 모든 하드 제약과 영향을 받는 집단을 계약 전에 열람할 수 있다.
- 배치 불가 원인에서 두 번 이하의 이동으로 관련 규정에 도달한다.
- 수첩을 열고 닫아도 현재 배치·선택·타이머 상태가 손실되지 않는다.
- 1024폭과 키보드 조작에서도 검색, 탭, 항목 링크를 사용할 수 있다.
