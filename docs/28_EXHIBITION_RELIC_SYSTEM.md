# 전시품 유물 시스템

- 상태: `DRAFT`
- 적용 범위: 시나리오 캠페인과 무한 영업의 런별 패시브 빌드, 종족·관계 인물 보상, 운영 수첩 컬렉션
- 현재 v2: 미구현. 기능적 뼈대와 런·프로필 저장 분리가 끝난 뒤 외부 부착한다.

## 1. 한 문장 정의

호텔 평판·종족 우호도·관계 인물의 조사 신뢰와 개인 호감도가 서로 다른 전시품 후보군을 열고, 플레이어는 영업 중 제시되는 무작위 후보 가운데 하나를 선택해 **현재 런이 끝날 때까지 지속되는 패시브 유물**로 보유한다.

전시품은 객실이나 시설 칸에 설치하지 않는다. 호텔의 진열장과 보관고에 놓였다는 설정만 가지며, 게임에서는 획득 즉시 자동 발동하는 누적 패시브 목록으로 취급한다.

## 2. 왜 전시품인가

- 관계와 평판이 대사·해금 숫자에 그치지 않고 실제 운영 빌드를 바꾼다.
- 같은 시드라도 어떤 전시품 제안을 선택했는지에 따라 예약·정비·위험 대응 전략이 달라진다.
- 공간 배치 변수를 늘리지 않으므로 객실 CSP의 가독성을 해치지 않는다.
- 한 런에서 얻은 조합은 사라지지만 발견 기록은 남아 반복 플레이와 도감 수집의 동기가 된다.

## 3. 후보군

| 후보군 | 자격 조건 | 성격 |
| --- | --- | --- |
| 공용 전시품 | 호텔 평판 단계 | 어느 빌드에도 사용할 수 있는 예약·정비·경제·정보 보조 |
| 종족 전시품 | 해당 종족 우호도와 관련 사건 | 그 종족의 손님·시설·시너지 운영을 강화하거나 위험을 완화 |
| 조사 신뢰 전시품 | 관계 인물의 조사 신뢰와 필수 조사 장면 | 예약 정보·사건 경고·조사 대응 중심 |
| 개인 호감도 전시품 | 관계 인물의 개인 호감도와 필수 개인 장면 | 인물의 성격과 관계를 반영한 별도 운영 방식 |

- 수치 임계치만 반복해서 넘기면 후보군을 열 수 없다. 관련 사건이나 장면을 함께 요구한다.
- 후보군 해금은 전시품을 즉시 확정 지급한다는 뜻이 아니라 이후 무작위 제안에 등장할 자격을 연다는 뜻이다.
- 종족·관계 임계치를 처음 충족하면 해당 출처 전용 후보 3개 중 하나를 고르는 `기념 전시품 제안`을 한 번 보장한다.
- 이후 일반 전시품 제안은 현재 열린 공용·종족·관계 후보군을 합친 풀에서 뽑는다.
- 조사 신뢰와 개인 호감도 후보는 같은 전력 예산을 사용한다. 연애 경로가 실무 협력 경로의 명백한 상위 호환이 되지 않는다.
- 관계 인물의 성별 표현이 달라도 공통 역할 ID가 같으면 기계적 후보군과 효과는 같다. 명칭·삽화·획득 대사만 표현에 맞게 변형할 수 있다.

## 4. 제안과 선택

전시품 제안은 시간 제한 영업 도중이 아니라 다음 순간에만 연다.

1. 챕터 또는 시즌 시작의 첫 빌드 선택
2. 중요 정산·감사 통과 보상
3. 호텔·종족 평판 단계 최초 도달
4. 관계 인물의 조사 신뢰·개인 호감도 임계 사건 완료
5. 명시된 희귀 사건 보상

기본 제안은 서로 다른 전시품 3개 중 하나를 선택한다. 정확한 장수와 제안 횟수는 밸런스 검증 뒤 조정한다.

- 이미 현재 런에서 보유한 전시품은 다시 제안하지 않는다.
- 같은 효과군만 세 개가 동시에 나오지 않게 후보 다양성 규칙을 둔다.
- 선택 전 효과, 발동 조건, 중복 방식과 해당 출처를 모두 공개한다.
- 선택하지 않은 전시품은 그 런의 이후 제안에 다시 나올 수 있다. 영구적으로 소실되지 않는다.
- 제안을 건너뛸 수 있게 하되, 건너뛰기 자체에 별도 보너스를 주지는 않는다.
- 무작위 결과는 런 시드와 제안 순번으로 재현한다. 새로고침으로 후보를 바꿀 수 없다.

### 일반 제안의 혼합 규칙

일반 제안은 다음 순서로 후보를 만든다.

1. 현재 평판·관계 상태로 열린 후보만 모은다.
2. 이미 보유한 전시품과 현재 사건에서 금지된 항목을 제거한다.
3. 가능한 경우 공용 1칸, 현재 운영과 관련된 종족·관계 후보 1칸, 전체 열린 풀의 자유 후보 1칸을 구성한다.
4. 특정 후보군이 비어 있으면 남은 열린 풀로 채운다.
5. 서로 사실상 같은 효과 세 개만 남으면 다시 추첨한다.

이 규칙은 전문 후보를 볼 기회를 보장하면서도 매번 같은 종족 장비만 고르는 정답 루프를 막는다.

## 5. 획득과 지속

- 선택한 전시품은 현재 런의 `보유 전시품`에 들어가며 즉시 자동 발동한다.
- 별도 활성 슬롯, 객실 배치, 소모 횟수, 내구도와 유지비는 없다.
- 획득한 전시품은 런 종료까지 모두 누적 활성화된다.
- 전시품 수를 제한하는 수단은 슬롯이 아니라 한 런의 제안 횟수, 후보 희귀도, 중복 금지와 효과 상한이다.
- 런이 종료되면 보유 전시품과 패시브 조합은 사라진다. 새 런에는 이전 런의 전시품을 가져오지 않는다.
- 새 런에서 영구적으로 남는 것은 도감의 발견·제안·획득 기록과 후보군 해금 자격뿐이다. 캠페인 관계 수치 자체는 무한 영업으로 복사하지 않는다.

## 6. 모드별 적용

### 시나리오 캠페인

- 호텔·종족·관계 진행으로 후보군을 연다.
- 프로필에 과거 획득 기록이 있어도 새 캠페인의 종족·관계 후보군은 현재 캠페인의 조건을 다시 충족해야 열린다. 아직 만나지 않은 인물·사건을 도감 기록이 미리 제안 풀에 넣지 않는다.
- 관계 임계 사건 직후 해당 출처의 기념 전시품 제안을 보장한다.
- 얻은 전시품은 해당 캠페인 런의 남은 영업 동안 지속된다.
- 직전 영업 재검토로 폐기된 경로에서 획득한 전시품과 후보 선택은 복원된다. 도감에는 그 경로에서 실제로 확정 획득한 것으로 남기지 않는다.

### 무한 영업

- 관계 수치를 직접 진행하지 않는다.
- 프로필에서 해금 자격을 얻은 종족·관계 후보군은 무한 영업의 제안 풀에 포함될 수 있다.
- 공용 후보의 세부 단계는 현재 무한 영업 런의 호텔 평판으로, 종족 후보의 가중치는 현재 투숙·종족 평판 상태로 다시 결정한다.
- 런 시작과 감사 통과 보상에서 무작위 전시품을 선택하며, 획득한 조합은 해당 무한 영업 런에만 남는다.
- 전시품 조합은 최고 기록과 함께 런 결과에 기록한다.

### 초대 심사판 `SHOWCASE`

현재 심사 흐름에는 전시품 제안을 추가하지 않는다. 정식 모드 뼈대가 연결된 차기 개발본에서 임시 전시품으로 먼저 검증한다.

## 7. 효과 설계 원칙

전시품은 전략을 바꾸는 유물이지만 객실 퍼즐의 기본 인과성을 무너뜨리지 않는다.

- 하드 제약을 무시하거나 불가능한 배치를 유효하게 만들지 않는다.
- 자동 배치, 정답 추천과 숨은 조건의 무조건 공개를 제공하지 않는다.
- 조건 없는 대량 평판·골드·만족도 상승을 제공하지 않는다.
- 한 전시품은 하나의 주 효과와 필요할 때 하나의 작은 보조 효과만 가진다.
- 효과는 예약, 배치 조작, 정비, 정보, 위험, 조건부 경제 중 한 축을 중심으로 한다.
- 발동 여부와 실제 이득은 해당 화면과 정산 원인 목록에서 확인할 수 있어야 한다.
- 같은 효과군에는 합산 상한이나 `최고값만 적용` 규칙을 둔다.
- 어떤 전시품도 기본 캠페인 완주나 무한 영업 첫 감사의 필수 조건이 되어서는 안 된다.

효과 템플릿 예시는 다음과 같다. 이름과 수치는 아직 확정하지 않는다.

| 효과군 | 가능한 효과 | 금지선 |
| --- | --- | --- |
| 예약 | 영업당 첫 후보 교체 비용 완화, 특정 공개 태그 후보 가중 | 원하는 손님 확정 생성 |
| 배치 조작 | 영업당 첫 객실 이동 시간 비용 일부 완화 | 하드 제약 무시·자동 최적 배치 |
| 정비 | 조건부 정비 비용 또는 소요 행동 완화 | 시설 상태 영구 고정 |
| 위험 | 특정 사고 징후를 한 단계 일찍 표시 | 사건 자동 해결 |
| 경제 | 특정 조건 달성 시 소액 보너스 | 무조건적인 큰 복리 수익 |
| 학습 | 결산에서 원인 단서 하나를 더 선명하게 표시 | 미투숙 조합의 도감 자동 완성 |

## 8. 도감 구조

운영 수첩에 `전시품` 분류를 별도로 둔다.

| 단계 | 조건 | 표시 |
| --- | --- | --- |
| 미조우 | 관련 출처가 아직 열리지 않음 | 항목과 총개수에서 숨김 |
| 단서 발견 | 후보군 자격 또는 관련 사건 공개 | 실루엣, 출처 범주와 넓은 획득 방향 |
| 제안 확인 | 선택 화면에 등장했으나 고르지 않음 | 명칭, 전체 효과와 출처, `미획득` 표식 |
| 획득 | 한 런에서 실제 선택함 | 유래, 최초 획득 런과 획득 장면 |
| 효과 확인 | 실제 발동함 | 발동 조건, 수치, 중복·상한, 사용 기록 |

각 항목은 이름·아이콘·유래, 후보군, 해금 경로, 효과와 상한, 최초 제안·획득·발동 기록, 관련 종족·인물·사건·시설 링크를 가진다.

도감 완성률 자체에는 강한 수치 보상을 붙이지 않는다. 모든 전시품 수집을 기본 엔딩이나 진 엔딩의 필수 조건으로 요구하지 않는다.

## 10. 검증 조건

- 전시품 없이도 기본 캠페인과 무한 영업 첫 감사가 완료 가능하다.
- 전시품이 하드 제약 판정과 유효 배치 집합을 직접 바꾸지 않는다.
- 같은 시드·제안 순번·자격 상태에서 같은 후보가 나온다.
- 저장 후 새로고침해도 현재 후보와 선택 결과가 바뀌지 않는다.
- 폐기한 재검토 경로의 전시품 획득과 발동 기록이 프로필 도감에 확정되지 않는다.
- 런 종료 뒤 보유 패시브는 사라지지만 도감의 제안·획득·발동 기록은 유지된다.
- 관계 인물 성별 표현을 바꿔도 후보군 효과와 해금 난도가 같다.
- 조사 신뢰와 개인 호감도 후보 중 어느 한 계열만 열어도 동급 운영 빌드가 가능하다.
- 모든 전시품을 한 런에서 얻을 수 없으며 후보 선택이 반복 런의 전략 차이를 만든다.

## 11. 구현 순서

1. 프로필과 모드 런 저장 영역 분리
2. 시드 고정형 `3개 제안 → 1개 선택 → 런 보유` 공통 상태 머신
3. 효과 ID·중복군 기반 패시브 평가기
4. 공용 전시품 3개만으로 시작부터 엔딩까지 첫 회귀 테스트
5. 종족 후보군 1세트와 우호도 임계 기념 제안 연결
6. 대표 관계 인물의 조사 신뢰·개인 호감도 후보군 각 1세트 연결
7. 운영 수첩의 단서·제안·획득·효과 확인 단계 연결
8. 밸런스 검증 뒤 종족·관계 인물별 콘텐츠 외부 부착

전시품 이름과 개수를 먼저 늘리지 않는다. 엔딩까지 굴러가는 뼈대에 무작위 제안과 패시브 평가기를 한 번 연결한 뒤 콘텐츠를 데이터로 추가한다.
