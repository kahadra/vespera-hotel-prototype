# 손님 데이터 규격과 최초 명단

- 상태: DRAFT FOR VALIDATION
- 적용 범위: 5시간 세로 단면

## 1. 데이터 구조

각 손님은 다음 필드를 가진다.

| 필드 | 형식 | 설명 |
|---|---|---|
| `id` | string | 변하지 않는 내부 식별자 |
| `name` | string | 플레이어에게 표시할 이름 |
| `species` | enum | 종족 ID |
| `rank` | enum | `COMMON`, `VIP` |
| `base_fee` | integer | 수용 후 영업 성공 시 기본 숙박비 |
| `satisfied_reputation` | integer | 모든 필수 조건에 맞게 배치했을 때 얻는 평판 |
| `reject_reputation` | negative integer | 사전 거절 시 평판 변화 |
| `cancel_reputation` | negative integer | 수용 후 취소 시 평판 변화 |
| `hard_constraints` | array | 확장용 개인 필수 조건. 세로 단면에서는 항상 빈 배열 |
| `soft_preferences` | array | 개인 및 등급 선호 사항 |
| `ui_tags` | array | 위험과 특징을 요약하는 아이콘 |

최종 평가 시 종족 데이터의 공통 조건을 손님 데이터 앞에 합친다.

## 2. 종족 데이터 구조

| 필드 | 설명 |
|---|---|
| `id` | 종족 식별자 |
| `name` | 표시 이름 |
| `common_hard_constraints` | 모든 종족 구성원이 공유하는 필수 숙박 조건 |
| `common_soft_preferences` | 모든 종족 구성원이 공유하는 선호 사항 |
| `visual_keywords` | 이후 설정집과 아트 방향에 사용할 키워드 |

## 3. 최초 종족

### 뱀파이어

- ID: `VAMPIRE`
- 공통 필수 조건: `sunny` 객실 사용 불가
- 공통 선호: `quiet` 객실이면 `+2`
- 시각 키워드: 야간, 우아함, 커튼, 어두운 적색
- 플레이 역할: 햇빛 객실을 포기하고 조용한 중앙 객실을 경쟁

### 수인

- ID: `BEASTKIN`
- 공통 필수 조건: `noisy` 객실 사용 불가
- 공통 선호: `sunny` 객실이면 `+2`
- 시각 키워드: 예민한 청각, 야외, 목재, 따뜻한 황색
- 플레이 역할: 엘리베이터 옆을 피하고 창문 객실을 선호

두 종족 모두 B열을 사용할 수 있어 조용한 객실을 둘러싼 경쟁이 발생한다.

## 4. 최초 손님 6명

### G01. Lune

- ID: `G01_LUNE`
- 종족: 뱀파이어
- 등급: 일반
- 기본 숙박비: 6
- 만족 평판: `+1`
- 거절: `-1`
- 막판 취소: `-3`
- 개인 선호: 3층이면 `+3`
- 역할: 높은 층의 조용한 객실을 노리는 기본 손님

### G02. Morrow

- ID: `G02_MORROW`
- 종족: 뱀파이어
- 등급: 일반
- 기본 숙박비: 6
- 만족 평판: `+1`
- 거절: `-1`
- 막판 취소: `-3`
- 개인 선호: 엘리베이터 거리 1 이상이면 `+2`
- 역할: B열 경쟁을 강화하는 기본 손님

### G03. Lady Nox

- ID: `G03_LADY_NOX`
- 종족: 뱀파이어
- 등급: 귀빈
- 기본 숙박비: 15
- 만족 평판: `+4`
- 거절: `-4`
- 막판 취소: `-7`
- 귀빈 등급 공통 조건: 이웃 객실이 모두 비어 있어야 함
- 개인 선호: 엘리베이터 거리 1 이상이면 `+4`
- 개인 선호: 3층이면 `+3`
- 역할: 넓은 빈 공간을 요구하지만 수입과 평판이 큰 손님

### G04. Aru

- ID: `G04_ARU`
- 종족: 수인
- 등급: 일반
- 기본 숙박비: 6
- 만족 평판: `+1`
- 거절: `-1`
- 막판 취소: `-3`
- 개인 선호: 1층이면 `+3`
- 역할: 햇빛과 낮은 층을 함께 원하는 기본 손님

### G05. Fen

- ID: `G05_FEN`
- 종족: 수인
- 등급: 일반
- 기본 숙박비: 5
- 만족 평판: `+1`
- 거절: `-1`
- 막판 취소: `-3`
- 개인 선호: Aru의 옆방이면 `+4`
- 개인 선호: 3층이면 `+3`
- 역할: 낮은 보상이지만 Aru 주변 공간을 강하게 점유하며, 비밀 통로로 두 손님의 층 선호를 동시에 만족시킬 수 있음

Fen과 Aru의 이웃 관계는 개인 선호다. 붙이지 않아도 배치할 수 있지만, 공간을 투자하면 추가 점수를 얻는다.

### G06. Garr

- ID: `G06_GARR`
- 종족: 수인
- 등급: 귀빈
- 기본 숙박비: 14
- 만족 평판: `+4`
- 거절: `-4`
- 막판 취소: `-7`
- 귀빈 등급 공통 조건: 이웃 객실이 모두 비어 있어야 함
- 개인 선호: 라운지와 이웃하면 `+5`
- 개인 선호: 엘리베이터 바로 옆이면 `+5`
- 개인 선호: 2층이면 `+3`
- 역할: 귀빈 동선 확보와 라운지 또는 방음 객실의 고득점을 함께 요구하는 손님

## 5. 첫 영업 명단

고정 수용:

- Lune
- Morrow
- Aru
- Fen

학습 목표:

- 종족 공통 필수 숙박 조건
- 객실 속성 선호
- 특정 손님 이웃 필수 조건
- 유효 배치 이후 점수 개선

## 6. 두 번째 영업 명단

고정 수용:

- Lune
- Aru

예약 신청:

- Morrow
- Fen
- Lady Nox
- Garr

하루 응대 한도는 총 5명이므로 신청자 네 명 중 최소 한 명을 거절해야 한다.

학습 목표:

- 일반 손님과 귀빈의 수익·평판 비교
- 공간을 많이 차지하는 귀빈의 기회비용
- 시설에 따라 달라지는 손님 가치
- 사전 거절과 높은 만족도의 교환 관계

## 7. 데이터 검증 조건

- 모든 ID는 고유하다.
- 취소 손실은 거절 손실보다 크다.
- 종족 공통 필수 조건만으로도 사용 가능한 객실이 하나 이상 존재한다.
- 첫 영업에는 유효 배치가 존재한다.
- 두 번째 신청 목록에는 세 시설 각각에서 유효한 5인 이하 부분집합이 존재한다.
- 각 시설은 최소 한 손님의 유효 객실 또는 선호 점수를 바꾼다.
- 귀빈을 받는 선택과 거절하는 선택의 결과가 모두 검산 기록에 남는다.
