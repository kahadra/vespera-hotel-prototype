# 세로 단면 테스트 계획

- 상태: `v2 INTERNAL FLOW PASS / EXTERNAL PLAYTEST NEXT`
- 목적: 기능 정상 동작과 코어 재미 판정을 분리한다.

## v2 필수 회귀 범위

### 데이터·생성

- 등급 집합이 정확히 N/R/SR/SSR이며 각 색·기호·단계·최소 평판이 유효하다.
- 4종족, 16손님, 5영업, 8개 시설과 순차 증축 데이터의 모든 참조가 유효하다.
- 평판별 등급 확률의 합이 항상 100이고, 단계 또는 최소 평판 전에는 상위 등급 일반 추첨 확률이 0이다.
- 동일 시드·단계·평판·제외 목록에서 손님과 공사 제안이 완전히 재현된다.
- 1회차는 N 고정, 2회차는 R 보장, 3회차는 SR 보장, 5회차는 쇼케이스 전용 SSR 초대를 포함한다.
- 보장·특별 초대가 일반 등급 확률이나 영구 해금 상태를 바꾸지 않는다.

### 공개 규정과 숨은 선호

- 만나지 않은 종족·등급 공개 규정은 `미열람 규칙`으로 보인다.
- 첫 신청이 도착하면 해당 종족·등급을 열람하며 등급 규정은 별도 조작 없이 자동 열람된다.
- 손님 카드에는 종족·등급·공개 개인 선호가 보이고 공통 규정 전문은 반복하지 않는다.
- 종족×등급 숨은 선호는 해당 손님의 영업 결산 전에는 정체가 보이지 않고 결산 뒤 같은 조합 전체에 열람된다.
- 숨은 선호는 양수 점수의 선택 사항만 허용한다. 숨은 필수 조건, 숨은 감점, 손님 개인 `hidden_*` 필드는 데이터 검증에서 실패한다.
- SR/SSR의 빈 이웃 객실 요청을 놓쳐도 영업을 마감할 수 있고, 만족 점수만 얻지 못한다.
- 숨은 선호가 공개 선호 목록과 중복 합산되지 않는다.

### 연박·객실 상태·재방문

- 2박 손님은 다음 영업에 자동 포함되고 첫 배정 객실이 고정된다.
- 연박 손님의 이동·회수·맞바꾸기와 투숙 객실 정비가 불가능하다.
- 연박 중에도 주변 구성과 시설에 따라 만족도를 매일 다시 계산한다.
- 투숙 뒤 청결·내구가 예고된 값만큼 감소하고 기준 미만 객실은 배정 후보에서 제외된다.
- 빈 객실 정비는 정확한 골드를 차감하고 청결·내구를 100으로 회복한다.
- 재방문 보너스가 직전 만족도 `0/5/10` 구간에서 각각 `+1/+2/+3`으로 계산된다.

### 시너지·상극·공사

- 같은 종족 인원 문턱에서 시너지 점수와 원인 문구가 적용된다.
- 지정 상극 종족이 같은 층일 때만 감점되고 다른 층에서는 적용되지 않는다.
- 시설·인테리어는 누적 보유되며 각 효과가 함께 평가된다.
- `F2-D`는 `F1-D` 없이, `F3-D`는 `F2-D` 없이 계약할 수 없다.
- `영업 준비 / 공사 계약`에서 동관 증축과 시설·인테리어를 구분하고 각 분류는 영업 사이 최대 1건만 계약할 수 있다.
- 연박 중인 객실에 직접 영향을 주는 시설·인테리어는 계약할 수 없고, 퇴실 뒤에는 다시 계약할 수 있다.
- 확장 계약을 하지 않아도 최소 하나의 유효 수용 부분집합과 객실 배정이 존재한다.

### 예약 응대 한도와 기존 배치

- 완공 객실이 9/10/11/12실일 때 예약 응대 한도는 각각 5/6/7/8명이다.
- 사용 가능 객실 수는 미증축, 시설 전환, 청결·내구 기준 미달을 제외해 응대 한도와 별도로 계산한다.
- 연박 손님은 수용 명단과 고정 객실에서 정확히 한 번씩 집계되고, 신규 배정 여유에서 고정 객실 한 실을 차감한다.
- 응대·물리 객실 한도 안에 있지만 필수 숙박 조건을 함께 만족하지 못하는 조합은 예약 확정 후 실제 배정 또는 긴급 배정에서 실패할 수 있다.
- 예약 객실도의 각 객실은 `연박 고정/사용 불가/미증축/빈 객실` 중 하나만 표시하며 실제 board state와 일치한다.
- 1024×720과 1280×720에서 객실도 버튼, 두 한도, 명단 확정 버튼이 접힘 없이 보인다.

### 전체 브라우저 흐름

1. 초대장과 진행 UI가 `개장 전 초청 영업`으로 통일되고, 압축 범위 안내는 제출 영상 초반에만 있는지 확인한다.
2. 시간 제한 없는 객실 배정 연습을 완료하거나 건너뛴다.
3. 1~5회 영업에서 예약, 객실 배정, 결산, 정비와 공사 계약을 반복한다.
4. 120초 만료, 비최적 긴급 배정, 필요한 강제 취소가 연박 객실 고정을 깨지 않는지 확인한다.
5. R/SR 보장, 숨은 선호 열람, 객실 마모, 누적 시설, 종족 효과를 한 세션에서 확인한다.
6. 영상의 SSR 시연 범위 안내가 초반에 한 번만 나오고, 5회차 카드와 최종 화면에서는 같은 설명을 반복하지 않는지 확인한다.
7. 플레이 UI에 검산된 최대 만족도나 `현재/최대` 형태가 노출되지 않는지 확인한다.
8. 플레이어 노출 문구에서 `퍼즐` 대신 영업·객실 배정·운영·공사 계약 용어를 사용하는지 확인한다.

## 8. 재미 판정

### PASS

- 3명 중 최소 2명이 유효 배치 이후 자발적으로 점수를 개선
- 3명 중 최소 2명이 시설이 바꾼 관계를 정확히 설명
- 3명 모두 외부 해법 없이 전체 세션 완료
- 거절 이유가 단순 등급 비교가 아니라 공간 또는 시설과 연결됨
- 무작위 맞바꾸기보다 조건을 읽는 행동이 관찰됨

### REVISE

- 완료는 가능하지만 유효 배치 직후 바로 마감
- 시설 선택 이유가 가격이나 숫자 크기에만 머묾
- 필수 조건이 맞지 않는 원인을 반복해서 놓침
- 상위 등급 둘을 받는 선택이 지나치게 명백함

### STOP

- 다수 플레이어가 조건을 읽지 않고 반복 대입
- 시설에 따라 해법이 달라졌다고 느끼지 못함
- 수용·거절이 귀찮은 사전 절차로만 인식됨
- 결과 화면을 보고도 점수 원인을 설명하지 못함

## 9. 배포본 테스트

- 강력 새로고침 후 데이터 로딩
- 콘솔 오류 없음
- 모든 상대 경로 정상

- 배포 URL에서 처음부터 최종 결과까지 진행
- ZIP 루트에 `index.html` 존재

## 10. 버그 우선순위

- P0: 진행 불가, 계산 오류, 유효 배치가 실패 처리됨
- P1: 잘못된 원인 표시, 시설 효과 누락, 상태 초기화 실패
- P2: 레이아웃 깨짐, 툴팁 누락, 애니메이션 이상
- P3: 문구, 정렬, 시각적 다듬기

P0와 P1이 하나라도 남으면 외부 배포하지 않는다.
