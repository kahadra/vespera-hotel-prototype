- 상태: INTERNAL VERIFICATION COMPLETE / EXTERNAL PLAYTEST NEXT
- 목적: 기능 정상 동작과 코어 재미 판정을 분리한다.

## 1. 테스트 층위

1. 데이터 정합성
2. 규칙 및 점수 계산
3. 화면 상태 전환
4. 전체 세션 행동 검증
5. 외부 플레이테스트
6. 배포본 검증

## 2. 데이터 검증

매 데이터 변경 후 실행한다.

```powershell
python .\tools\validate_prototype_puzzles.py
```

### 통과 조건

- 종료 코드 0
- 첫 영업 최고 평가 35
- 방음 객실 최고 평가 60
- 라운지 최고 평가 63
- 비밀 통로 최고 평가 62
- 각 시나리오에 유효 배치 존재
- 취소 손실이 거절 손실보다 큼

## 3. 규칙 기능 테스트

### 객실 속성

- 뱀파이어를 C열에 배치하면 공통 필수 조건 미충족
- 수인을 A열에 배치하면 공통 필수 조건 미충족
- 방음 객실 구매 후 Garr를 `F2-A`에 배치하면 공통 필수 조건 충족
- 라운지 구매 후 `F2-B`에 손님 배치 불가

### 관계

- Fen과 Aru가 같은 층 B/C면 이웃 조건 충족
- 서로 다른 층이면 기본적으로 불충족
- 비밀 통로 구매 후 `F1-B`와 `F3-C`는 이웃
- 비밀 통로의 이웃 관계가 귀빈 등급의 빈 옆방 필수 조건에도 적용

### 점수

- Lune `F3-B`: 5점
- Morrow `F2-B`: 4점
- Aru `F1-C`: 5점
- Garr `F2-A` + 방음: 8점
- Garr `F2-C` + 라운지: 10점
- 비밀 통로 끝 객실: 투숙객마다 시설 점수 3점

## 5. 상태 전환 테스트

- 모든 화면에서 운영 수첩 열기와 `Esc` 닫기 가능
- 첫 영업 전 귀빈 등급 규정은 잠금 상태
- 귀빈 예약 등장 후 등급 규정과 필수 조건 해금
- 손님 카드에는 종족·등급·개인 선호만 표시
- 첫 영업 필수 조건 미충족 중 마감 불가
- 첫 결과 전 시설 화면 접근 불가
- 보유 골드보다 비싼 시설 구매 불가
- 시설 구매 후 골드 정확히 차감
- 두 번째 예약에 미결정 손님이 있으면 확정 불가
- 응대 한도 5명 초과 불가
- 거절 손실이 최종 결과에 반영
- 재시작 시 골드·평판·시설·배치 초기화
- 두 번째 영업 재도전 시 첫 결과와 시설 유지

## 7. 외부 플레이테스트

최소 3명에게 사전 설명 없이 링크만 제공한다. 개발자는 조작법이나 해법을 말하지 않는다.

### 관찰 항목

- 첫 손님을 배치하기까지 걸린 시간
- 필수 조건과 선호 사항을 구분하는 시점
- 처음 유효 배치를 만든 뒤 배치를 더 바꾸는지
- 시설 설명을 읽고 구매 이유를 말할 수 있는지
- 수용·거절에서 10초 이상 비교하는지
- 점수가 변한 이유를 설명할 수 있는지
- 비밀 통로의 추가 이웃 관계를 이해하는지
- 재도전 의사와 그 이유

### 질문

플레이 후에만 묻는다.

1. 가장 고민한 선택은 무엇이었는가?
2. 점수를 올리기 위해 어떤 배치를 바꿨는가?
3. 선택한 시설이 두 번째 문제를 어떻게 바꿨는가?
4. 왜 그 손님을 거절했는가?
5. 이해되지 않거나 불공정하다고 느낀 규칙은 무엇인가?
6. 다시 한다면 무엇을 다르게 하겠는가?

## 8. 재미 판정

### PASS

- 3명 중 최소 2명이 유효 배치 이후 자발적으로 점수를 개선
- 3명 중 최소 2명이 시설이 바꾼 관계를 정확히 설명
- 3명 모두 외부 해법 없이 전체 세션 완료
- 거절 이유가 단순 등급 비교가 아니라 공간 또는 시설과 연결됨
- 무작위 맞바꾸기보다 조건을 읽는 행동이 관찰됨

### REVISE

- 완료는 가능하지만 유효 배치 직후 바로 마감
- 시설 선택 이유가 가격이나 숫자 크기에만 머묾
- 필수 조건이 맞지 않는 원인을 반복해서 놓침
- 귀빈 둘을 받는 선택이 지나치게 명백함

### STOP

- 다수 플레이어가 조건을 읽지 않고 반복 대입
- 시설에 따라 해법이 달라졌다고 느끼지 못함
- 수용·거절이 귀찮은 사전 절차로만 인식됨
- 결과 화면을 보고도 점수 원인을 설명하지 못함

## 9. 배포본 테스트

- 강력 새로고침 후 데이터 로딩
- 콘솔 오류 없음
- 모든 상대 경로 정상
- 1280×720과 1024×720 확인
- 1024 폭에서도 수첩 버튼, 골드, 평판 카드가 한 줄에 정렬
- 예약 손님 4명이 한 화면의 4열 카드로 비교 가능
- Chrome과 Edge 최신 로컬 설치본 확인
- 배포 URL에서 처음부터 최종 결과까지 진행
- ZIP 루트에 `index.html` 존재

## 10. 버그 우선순위

- P0: 진행 불가, 계산 오류, 유효 배치가 실패 처리됨
- P1: 잘못된 원인 표시, 시설 효과 누락, 상태 초기화 실패
- P2: 레이아웃 깨짐, 툴팁 누락, 애니메이션 이상
- P3: 문구, 정렬, 시각적 다듬기

P0와 P1이 하나라도 남으면 외부 배포하지 않는다.
