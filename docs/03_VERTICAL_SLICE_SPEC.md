# 프로토타입 명세

- 상태: `v2 IMPLEMENTED`
- 현재 권위 범위: 튜토리얼 + 5회 실제 영업의 압축 쇼케이스
- 보존 범위: 이 문서 뒤쪽의 `v1` 2영업 세로 단면 기록
- 목적: 전체 게임의 성장 속도를 복제하지 않고, 배치·학습·경영의 연결과 콘텐츠 폭을 짧은 심사 세션에서 보여 준다.
- 목표 플레이 시간: 약 10~15분
- 목표 배포: 브라우저 실행 빌드

## v2 현재 구현 기준

### 쇼케이스 고지

- 시작 화면과 진행 UI는 `개장 전 초청 영업`으로 표현하고, 압축 성장 범위는 제출 영상 초반에 한 번만 명시한다.
- N/R/SR/SSR과 시설 희귀도가 5회 안에 빠르게 등장하는 것은 심사용 압축이며 정식 게임의 성장 밸런스가 아니다.
- 5회차 SSR은 쇼케이스 전용 특별 초대다. 정식 게임에서 SSR이 영구 해금되었음을 뜻하지 않는다.

### 전체 흐름

1. 초대장 형식의 시작 화면
2. 시간 제한 없는 2인 배치 튜토리얼 또는 건너뛰기
3. 1회차 고정 N 손님 배치
4. 영업 정산, 객실 마모 확인, `영업 준비 / 공사 계약`
5. 2~5회차의 시드 기반 신청 수용·거절, 연박 객실 확인, 120초 배치
6. 각 영업 결산에서 수입·평판·현재 만족도, 숨은 선호 열람, 재방문 기록 확인
7. 마지막 종합 결과

실제 영업은 모두 120초다. 첫 배치는 무료이고 이미 놓은 손님의 이동·회수·맞바꾸기는 5초를 소비한다. 수첩을 연 동안 시간은 멈추며, 시간 초과 시 필수 조건을 만족하는 비최적 긴급 배치와 필요한 강제 취소를 적용한다.

### 5회 진행과 압축 해금

| 회차 | 제안 구성 | 보여 줄 성장 층위 |
|---:|---|---|
| 1 | 고정 N 손님 | 종족 필수 조건, 공개 개인 선호, 기본 배치 |
| 2 | 평판 확률 신청 + R 보장 | 첫 상위 등급 규정, 수용·거절, 시드 제안 |
| 3 | 평판 확률 신청 + SR 보장 | 고가치 선택 선호, 연박·객실 상태 압박 |
| 4 | 평판 확률 신청 | 종족 시너지·상극과 누적 개선 조합 |
| 5 | 평판 확률 신청 + 쇼케이스 전용 SSR 초대 | 최종 등급 표현과 종합 운영 판단 |

등급 확률은 평판 구간에서 합계 100%를 유지하되 단계 잠금을 먼저 적용한다. 보장 손님과 특별 초대는 시연 전달을 위한 예외이며 일반 확률 해금을 영구 변경하지 않는다.

### 규칙 정보의 세 층

- 종족·등급의 공개 공통 규정은 만나기 전 `미열람 규칙`으로 표시한다. 해당 신청이 처음 도착하면 읽을 수 있고, 등급 규정은 첫 신청 시 자동 열람된다.
- 손님 카드에는 종족, N/R/SR/SSR 등급, 공개 개인 선호와 예약 운영 정보만 표시한다.
- 종족×등급의 `숨은 선호`는 양수 점수만 주는 선택 사항이다. 해당 조합 손님의 투숙 결산 뒤 열람되며 밤 마감을 막지 않는다.
- `양옆 객실이 비어 있음`은 SR/SSR의 고득점 사생활 선호이며 필수 조건이 아니다.

### 시간축과 경영

- 2박 손님은 첫날 배정 객실을 다음 영업에도 유지하며 이동할 수 없다.
- 만족도는 매일 주변 손님과 시설을 기준으로 다시 계산한다.
- 재방문 손님은 직전 만족도 구간에 따라 보너스를 얻는다.
- 투숙은 객실 청결·내구도를 낮춘다. 기준 미만 객실은 배정할 수 없고, 영업 사이 골드를 내 정비할 수 있다.
- `영업 준비 / 공사 계약`에서 빈 객실을 정비하고, `동관 증축`과 `시설·인테리어`를 나눠 각 최대 1건을 계약한다. 시설은 함께 보유되며 증축은 `F1-D → F2-D → F3-D` 순서만 허용한다. 연박 중인 객실에 직접 영향을 주는 인테리어는 퇴실 전까지 잠긴다. 공사는 객실 배정 선택지를 넓히되 필수 진행 조건으로 강제하지 않는다.
- 예약 응대 한도는 기본 5명이며 완공된 동관 객실마다 1명씩 증가한다. 사용 가능 객실 수는 미증축·시설 전환·미정비 객실을 제외해 별도로 계산하고, 연박 손님은 응대 인원과 객실 점유에 모두 포함한다.
- 예약 화면에서 사전 확정 손님과 연박 고정 객실을 분리해 표시하고, 읽기 전용 객실도에서 기존 배치를 확인할 수 있다. 두 인원 상한 안에 들어도 필수 숙박 조건의 조합 가능성은 보장하지 않는다.
- 같은 종족 인원은 시너지를 만들고, 특정 종족 조합은 같은 층에서 상극 감점을 만든다.

### v2 구현 완료 정의

- 같은 시드에서 같은 신청과 개선 제안이 재현된다.
- 튜토리얼부터 5회차 결과까지 새로고침 없이 진행된다.
- 연박 손님이 첫 객실을 유지하고 객실 마모·정비가 다음 영업의 가용 객실을 바꾼다.
- 공개 규정, 공개 개인 선호, 숨은 선호가 UI와 점수 출처에서 섞이지 않는다.
- N/R/SR/SSR 태그, 평판 확률, 누적 시설, 순차 증축, 시너지·상극이 실제 계산에 반영된다.
- 확장하지 않아도 최소 하나의 합리적인 수용 부분집합과 유효 배치가 존재한다.
- 5회차 SSR 초대에 쇼케이스 전용 안내가 표시된다.

## v1 보존 기록 — 최초 2영업 세로 단면

아래 내용은 5시간 안에 코어 연결을 처음 검증한 v1의 범위와 판정 기준이다. 현재 v2 기능·밸런스·화면 흐름의 권위 기준으로 사용하지 않는다.

1. 필수 조건을 맞춘 뒤 선호 점수를 최적화하는 과정이 재미있는가?
2. 수용과 거절이 서로 다른 합리적 결과를 만드는가?
3. 영업 점수가 다음 성장 선택으로 자연스럽게 연결되는가?
4. 시설 선택이 다음 퍼즐의 해법을 바꾸는가?
5. 종족과 손님 등급이 조건을 직관적으로 설명하는가?

## 전체 흐름

1. 시작 화면
2. 시간 제한 없는 2인 배치 연습 또는 건너뛰기
3. 고정 예약 명단으로 120초 첫 영업
4. 첫 영업 결과와 수입 정산
5. 시설 제안 3개 중 하나 선택
6. 두 번째 예약 신청자 수용 또는 거절
7. 선택한 시설이 적용된 120초 두 번째 영업
8. 최종 평가
9. 즉시 재시작

## 배치 연습과 영업 마감

- 배치 연습에는 Lune과 Morrow만 등장하며 시간 제한이 없다.
- 시작 초대장과 연습 화면에서 모두 연습을 건너뛸 수 있다.
- 연습을 풀거나 건너뛰면 동일한 상태의 첫 영업으로 진입한다.
- 첫 영업과 두 번째 영업의 체크인 마감은 각각 120초다.
- 아직 배정되지 않은 손님의 첫 배치는 무료다.
- 이미 배정한 손님을 이동·회수하거나 점유 객실과 맞바꾸면 5초가 차감된다.
- 운영 수첩을 연 동안에는 시간이 흐르지 않는다.
- 시간이 끝나면 프런트가 필수 조건만 만족하는 첫 유효 배치를 사용하며 선호를 최적화하지 않는다.
- 모든 예약을 지킬 유효 배치가 없을 때는 최근 수용 손님부터 필요한 만큼 강제 취소하고, 일반 거절보다 큰 평판 손실을 적용한다.

## 시설 제안

서로 다른 관계를 바꾸는 세 시설을 사용한다.

1. 방음 객실, 25골드: `F2-A`의 소음을 제거해 수인 상위 등급의 새 해법 제공
2. 라운지, 30골드: 객실 하나를 점유하고 주변 손님의 시설 선호 증가
3. 비밀 통로, 35골드: 떨어진 두 객실을 이웃으로 만들고 두 끝 객실에 점수 제공

각 시설은 두 번째 퍼즐에서 최소 하나의 필수 조건 또는 선호 계산을 실제로 변경해야 한다.

## 두 번째 예약

신청자 3명의 카드에 다음 정보를 표시한다.

- 종족
- 등급
- 숙박비
- 종족·등급 공통 조건과 개인 선호
- 수용 성공 시 평판
- 거절 시 평판 손실

최소 한 명은 높은 보상과 높은 배치 위험을 가진다. 세 명을 모두 받는 선택과 한 명을 거절하는 선택이 모두 합리적일 수 있어야 한다.

## 두 번째 영업

- 첫 영업과 같은 3×3 보드
- 선택한 시설 적용
- 신청자 선택에 따라 손님 구성이 달라짐
- 일반 및 높은 등급 손님 포함
- 필수 조건 충족 후 서로 다른 점수 최적화 가능

## 구현 완료 정의

- 처음부터 최종 결과까지 새로고침 없이 진행 가능
- 두 번째 영업에 시설 및 수용 선택이 반영됨
- 필수 조건 미충족과 점수 원인을 텍스트로 확인 가능
- 같은 초기 상태에서 결과를 재현할 수 있음
- 재시작 후 모든 상태가 초기화됨
- 브라우저 배포본에서 로컬과 같은 결과가 나옴

## 시간 초과 시 제거 순서

1. 팁의 무작위 변동을 고정값으로 변경
2. v1 일정 초과 시 드래그를 클릭 선택 방식으로 단순화
3. 시설 연출과 구매 애니메이션 제거
4. 높은 등급 손님의 전용 시각 표현 제거
5. 최종 평가를 한 화면의 텍스트 요약으로 축소

필수 조건 검증, 선호 점수, 수용·거절, 시설이 두 번째 퍼즐을 바꾸는 기능은 제거하지 않는다. 이 네 요소가 세로 단면의 검증 대상이다.

## 플레이테스트 판정

### PASS

- 플레이어가 유효 배치 후 점수를 더 올리려 시도함
- 시설 선택 이유와 두 번째 퍼즐의 변화를 설명함
- 수용·거절 중 고민이 관찰됨
- 점수와 충돌 원인을 이해함

### REVISE

- 규칙은 이해하지만 최고점이 명백하거나 시설 선택이 숫자 보너스로만 느껴짐
- 거절이 항상 정답 또는 항상 오답임

### STOP

- 배치가 무작위 맞바꾸기 작업으로만 느껴짐
- 시설과 손님 선택이 다음 해법에 의미 있는 차이를 만들지 못함
