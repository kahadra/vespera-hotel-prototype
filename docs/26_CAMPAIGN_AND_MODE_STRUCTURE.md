# 시나리오 캠페인과 무한 영업 구조

- 상태: `PROPOSED`
- 적용 범위: 정식판의 모드, 캠페인 시간축, 종족·관계 인물 분기, 성별 선택, 엔딩과 세이브 경계
- 비적용 범위: 현재 v2의 5회 개장 전 초청 영업

이 문서는 정식판의 전체 플레이 구조를 소유한다. 구체적인 종족 규칙과 시너지 계산은 `25_SPECIES_AND_SYNERGY_SYSTEM.md`, 영구 지식과 UI는 `27_OPERATIONS_HANDBOOK.md`, 제작 순서와 통과 조건은 `02_PRODUCTION_ROADMAP.md`를 따른다.

## 1. 두 모드의 역할

| 구분 | 시나리오 캠페인 | 무한 영업 |
| --- | --- | --- |
| 중심 경험 | 종족·인물·운영 방향 선택과 여러 엔딩 | 객실 배정·시설·아이템 빌드와 생존 기록 |
| 콘텐츠 구성 | 제작된 공통 흐름, 조건부 종족 영업, 별도 사건 장면 | 시드 기반 신청·공사·계약과 시즌 변형 |
| 길이 | 경로에 따라 달라지는 유한 캠페인 | 평판 감사에 실패할 때까지 지속 |
| 평판 역할 | 시장·시나리오·협약·엔딩 조건 | 콘텐츠 해금과 시즌 생존 판정 |
| 실패 | 운영 목표 실패 또는 제한된 결말 | 감사 미달 시 호텔 폐업과 런 종료 |
| 반복 이유 | 다른 종족 방향, 관계와 엔딩 | 다른 시드, 시설·아이템 조합과 최고 생존 기록 |

시나리오를 100~200개의 선형 영업으로 늘리지 않는다. 캠페인은 서사적 완결과 선택 결과를 담당하고, 장기 반복 운영은 무한 영업이 담당한다.

### 새 게임의 성별 설정

정식 캠페인의 플레이어는 인간 지배인으로 고정한다. 새 게임에서는 플레이어와 표준 관계 인물의 성별 표현을 정하며, 기존 문서의 `히로인`은 이후 성별 선택이 가능한 `관계 인물`로 통칭한다. 플레이어 종족은 선택값이나 세이브 변수가 아니다.

| 설정 | 기본값 | 선택지 | 적용 범위 |
| --- | --- | --- | --- |
| 플레이어 종족 | 인간 | 선택 없음 | 지배인 역할과 세계관에서 고정 |
| 플레이어 성별 | 남성 | 남성 / 여성 | 플레이어 호칭·대명사와 자기표현만 변경 |
| 관계 인물 성별 프리셋 | 여성 5명 | 전원 여성 / 남성 중심 / 역할별 개별 선택 | 이름·외형·호칭·초상·도트·일부 배경 설정과 개인 장면 |
| 비서 오토마타 외형 | 선택 필요 | 남성형 / 여성형 | 초상·음성·호칭 표현만 변경, 역할과 기능은 동일 |

- 플레이어 성별과 관계 인물 성별은 서로 독립적으로 선택한다. 플레이어 성별은 호텔 운영, 일반 손님의 반응, 조사 협력, 호감도, 관계 엔딩이나 보상을 바꾸지 않는다.
- `남성 중심`에서는 인족·뱀파이어·늑대인간·몽마 관계 인물을 남성으로 두고 마녀 관계 인물은 여성으로 유지한다.
- `역할별 개별 선택`에서는 공개된 우호·중립 관계 인물 슬롯마다 남성 또는 여성을 정하되 마녀는 여성으로 잠근다. 숨은 적대 인물이나 미공개 관계선을 선택 화면에서 누설하지 않는다.
- 선택은 캠페인 세이브를 만든 뒤 고정한다. 진행 중 변경으로 이름·초상·회상 기록이 뒤섞이지 않게 하며, 다른 조합은 새 캠페인에서 선택한다.
- 성별 변형은 시나리오 역할, 핵심 성격, 종족 사건의 원인, 조사 기능, 관계 조건과 결말의 의미를 바꾸지 않는다.
- 변형 가능한 부분은 이름, 외형, 호칭, 사회적 기대, 가족·공동체와의 관계, 일부 과거 경험, 대사와 장면 연출이다. 같은 문장에 호칭만 치환하는 수준으로 끝내지 않되 완전히 별개의 시나리오 두 개로 분기하지도 않는다.
- 몽마 관계 인물은 여성형에서 서큐버스, 남성형에서 인큐버스 계통으로 표시한다. 꿈·계약·전환 출신이라는 핵심 역할과 퍼즐 기능은 동일하다.
- 마녀는 여성만 존재하므로 마녀 관계 인물은 항상 여성이다. 남성형 이름·초상·도트·개인 장면은 제작하지 않는다.
- 일반 손님은 성별 선택이나 성별 데이터의 대상이 아니다. 손님의 객실 규칙·만족도·시너지와 종족 시나리오는 플레이어 또는 손님의 성별을 참조하지 않는다.
- 캠페인에서 성별별 이름·외형·초상·도트와 세부 서사를 제작하는 인물은 표준 관계 인물 5명이며, 비서 오토마타는 세부 서사 분기 없이 남성형·여성형 표현 자산만 별도로 가진다.
- 비서 오토마타는 일반 손님이나 표준 관계 인물 5명에 포함하지 않는 고정 운영 보조 역할이다. 외형 선택은 별도로 저장하며 관계·로맨스·종족 규칙과 교차하지 않는다.
- 내부 데이터는 공통 `character_role_id` 아래 허용된 `MALE`과 `FEMALE` 표현 변형을 두고, 진행 플래그·호감도·조사 신뢰·엔딩 조건은 역할 ID를 기준으로 저장한다. 마녀 역할은 `FEMALE` 변형만 가진다.

```json
{
  "player_gender": "MALE",
  "relationship_gender_preset": "ALL_FEMALE",
  "relationship_character_gender_by_role": {
    "RELATIONSHIP_HUMAN": "FEMALE",
    "RELATIONSHIP_VAMPIRE": "FEMALE",
    "RELATIONSHIP_WEREWOLF": "FEMALE",
    "RELATIONSHIP_WITCH": "FEMALE",
    "RELATIONSHIP_DREAM_DEMON": "FEMALE"
  }
}
```

`relationship_gender_preset`은 `ALL_FEMALE`, `MALE_CENTERED`, `PER_ROLE` 중 하나다. `MALE_CENTERED`와 `PER_ROLE`에서도 `RELATIONSHIP_WITCH`는 항상 `FEMALE`로 검증한다. 프리셋을 선택해도 최종 저장은 관계 인물 역할별 값으로 펼쳐 두어 세이브 마이그레이션과 회상 재생에서 같은 인물을 재현한다. 이 필드는 일반 손님 데이터에 추가하지 않는다. 내부 ID는 가칭이며 구현 착수 시 데이터 명명 규칙에 맞춰 확정한다.

`secretary_automata_presentation`은 `MALE` 또는 `FEMALE`이며 캠페인 생성 뒤 고정한다. 어느 값을 골라도 같은 장면 ID와 상태 전환을 사용하고 표현 자산만 교체한다.

## 2. 콘텐츠 시간 단위

| 단위 | 정의 | 캠페인 영업 기한 | 별도 장면 시간 |
| --- | --- | --- | --- |
| 일반 영업 | 예약·배치·정산·공사로 이어지는 기본 운영 | 소모 | 없음 |
| 사건 영업 | 종족·시설·조사 규칙이 적용된 특수 운영 | 소모 | 전후 장면 가능 |
| 종족 에피소드 | 갈등, 선택, 협약과 결과를 다루는 장면 | 직접 소모하지 않음 | 소모 |
| 관계 인물 장면 | 개인 관계와 감정적 선택 | 직접 소모하지 않음 | 자유시간 슬롯 소모 |
| 메인 장면 | 챕터 도입·전환·결산 | 소모하지 않음 | 소모 |
| 숨은 조사 장면 | 여러 종족 사건의 증거 연결 | 소모하지 않음 | 숨은 분기에서만 발생 |

대화 장면을 객실 배정 없는 가짜 스테이지로 세지 않는다. 종족 에피소드의 기본 리듬은 `발단 장면 → 사건 영업 → 결과·방향 선택 장면`이다.

메인·종족 장면과 관계 인물 장면은 같은 선택 자원을 사용하지 않는다. 종족 사건을 해결하느라 개인 관계를 볼 수 없거나, 개인 관계를 보느라 캠페인의 필수 진상을 놓치는 구조를 기본값으로 두지 않는다.

### 시나리오 전용 하루 개시와 마감 장면

```text
DAY_OPENING
→ 비서 오토마타의 예약·객실 브리핑과 당일 시나리오
→ 예약 → 배치 → 정산
→ RESULT_REVIEW 마감 보고
→ 마감 서명: 다음 진행
  또는 아침 장부 재열람: 같은 DAY_OPENING
```

아침 브리핑은 별도 시간이나 영업 횟수를 소모하지 않는다. 당일 사건 조건, 이전 선택에 따른 대사와 운영 주의점을 전달하는 시나리오 장면이다. 마감 보고에서 기능명이나 세계관 원리를 설명하지 않고, 지배인이 비서에게 아침 장부를 다시 읽어 달라고 요청하는 대화만 제공한다. 같은 날을 반복한 뒤 비서가 처음 펼친 장부에 기시감을 느끼거나 지배인이 다음 내용을 미리 아는 정황으로 단서를 축적한다.

비서와 아침·마감 대화를 거치는 절차는 시나리오 캠페인에만 적용한다. 무한 영업은 반복 속도를 위해 이 장면을 생략하지만 정산에 `이번 영업 다시` 버튼을 직접 제공한다. 이 기능에는 예지, 세계선이나 다른 서사적 해석을 붙이지 않는다. 현재 `SHOWCASE` 초청 영업은 심사 흐름을 위해 재시도 UI를 표시하지 않는다.

## 3. 캠페인 볼륨과 경로

공개 구조는 5개 챕터를 유지하되 챕터마다 같은 수의 영업을 강제하지 않는다. 스테이지 수는 목표가 아니라 필요한 규칙 학습과 결산의 결과다.

| 구성 | 제안 범위 | 역할 |
| --- | ---: | --- |
| 공통 캠페인 | 36~40 영업 | 기본 경영, 종족 소개, 운영 방향과 최종 목표 |
| 종족 특수 영업 | 종족당 약 3 | 특화 시설 체험, 협약 선택, 혼합 숙련 |
| 기본 엔딩 분기 | 6~8 영업 | 안정 운영과 호텔 목표 결산 |
| 종족·관계 엔딩 분기 | 8~10 영업 | 선택한 관계와 운영 방향의 결산 |
| 숨은 조사 챕터 | 6~8 영업 | 새로운 조사 규칙 학습과 기존 사건 재해석 |
| 숨은 결전 챕터 | 6~8 영업 | 전 종족 제약, 조사와 최종 운영의 결합 |

예상 1회 플레이 길이는 다음과 같다.

- 안정 운영·기본 엔딩: 약 42~48 영업
- 일부 종족·관계 엔딩: 약 48~59 영업
- 모든 우호 종족을 깊게 진행한 최고난도 경로: 약 63~73 영업

이 숫자는 제작 전 검산을 위한 범위이며 확정 분량이 아니다. 공통 영업을 늘려 분량을 맞추지 않고, 대표 레벨의 판단이 반복되면 줄인다.

## 4. 공개 챕터 흐름

| 구간 | 역할 |
| --- | --- |
| 프롤로그 | 현재 v2와 연결되는 개장 전 시험 운영, 기본 규칙과 예약 원본 열람 |
| 챕터 1 | 호텔 상속, 최종 운영 목표, 공용 시설과 낮은 위험 손님 |
| 챕터 2 | 우호 종족 확대, 첫 종족 에피소드와 특화 시설 체험 |
| 챕터 3 | 전문화·중재·화합 선택, 관계 인물 등장과 첫 조사 신뢰 |
| 챕터 4 | 종족 협약 누적, 시너지 강화·악화·반전과 복합 제약 |
| 챕터 5 | 기본 경로의 운영·관계 결산과 조건별 엔딩 분기 |

각 챕터는 새 규칙을 무조건 추가하지 않는다. 이전에 배운 규칙을 다른 호텔 구조, 시설 조합과 종족 관계에서 다시 해석하게 한다.

종족 에피소드는 외부 종족 간 상극만 다루지 않는다. 뱀파이어·늑대인간·몽마의 자연 출생과 전환 출신 사이의 신분 갈등, 마녀 공동체의 선천과 각성 경험 차이도 사건 축으로 사용할 수 있다. 마녀 각성이 실제 구조였는지 조작된 구원이었는지는 개별 인물 사건에서 다룬다. 출신은 선악이나 객실 적합도를 자동 결정하지 않으며, 사건 선택과 실제 혼합 운영으로 관계 상태가 바뀌어야 한다.

## 5. 평판과 관계 상태

| 상태 | 책임 |
| --- | --- |
| 호텔 평판 | 일반 시장, 손님 등급, 호텔 전체 신뢰와 공사 후보 |
| 종족 평판 | 종족 손님, 시나리오, 특화 시설·협약과 종족 전시품 후보군 |
| 종족 방향 | 전문화·중재·화합 중 현재 선택과 영구 운영 변화 |
| 연합 신뢰 | 여러 종족을 함께 운영한 결과와 공동 조사 가능성 |
| 관계 인물 조사 신뢰 | 종족 사건, 조사 지원과 실무형 전시품 후보군 |
| 관계 인물 개인 호감도 | 개인 장면, 최종 선택·관계 엔딩과 개인 전시품 후보군 |

종족 평판은 시나리오를 여는 열쇠이고, 사건의 선택과 실제 운영 결과가 협약 상태를 결정한다. 반복 영업으로 누적 숫자만 올려 모든 분기를 여는 구조를 허용하지 않는다.

여러 종족의 평판 기준을 독립적으로 최대치에 가깝게 두지 않는다. 결합 조건은 전체 도달 가능 상태 공간에서 검산하고, 한두 번의 낮은 결과가 최고난도 경로를 즉시 영구 봉쇄하지 않게 한다.

## 6. 종족 방향과 난도

| 방향 | 운영 특성 | 보상 | 장기 영향 |
| --- | --- | --- | --- |
| 전문화 | 다른 종족을 배제하거나 층을 분리해 해법 단순화 | 자종족 시설·수입·희귀 손님 강화 | 특정 종족 결말에 유리, 연합 조사 비용 증가 |
| 실리적 중재 | 선택한 일부 집단만 협력 | 제한된 혼합 시너지와 관리 가능한 위험 | 기본·관계 경로 모두 가능 |
| 화합 | 여러 종족의 시설·인원·공간 조건을 동시에 관리 | 높은 점수 상한, 공동 시설·손님·연합 신뢰 | 최고난도 경로 접근 비용 감소 |

전문화는 낮은 가치의 나쁜 선택이 아니다. 안정 운영과 특정 종족·관계 엔딩을 위한 합리적인 해법이다. 화합은 기존 상극을 무료로 제거하지 않고, 복합 조건을 만족했을 때만 높은 보상으로 반전한다.

전문화 선택 하나가 숨은 최고난도 경로를 즉시 영구 봉쇄하지 않는다. 대신 늦은 화해 영업, 시설 철거·재건, 종족 평판 회복, 관계 인물의 중재 또는 추가 증거가 필요하다.

## 7. 관계 인물 구조

- 1차 본편은 우호·중립 5종족에 대응하는 표준 관계 인물 5명을 기준으로 한다.
- 관계 인물은 호텔 소속이 아니라 외부에 자기 생활과 공동체를 가진 손님으로 처음 등장한다.
- 진행 단계는 `첫 방문 손님 → 단골 손님 → 종족 연락책 → 조사·운영 협력 NPC → 선택적 상주 동반자`를 기준으로 한다. 모든 인물이 마지막 단계까지 가거나 호텔에 거주할 필요는 없다.
- 협력 NPC가 되어도 일상 접객 직원으로 배치하지 않는다. 중립 오토마타가 접객을 담당하고, 관계 인물은 종족 정보·협약·시설·사건 대응·조사·전시품 후보와 특수 선택지를 제공한다.
- 조사 신뢰는 여러 관계 인물과 동시에 높일 수 있고 종족 사건·공동 조사 지원에 사용한다.
- 개인 호감도는 제한된 자유시간과 장면 선택을 사용한다.
- 일반·종족 경로에서는 모든 관계 인물의 개인 관계를 한 런에서 완성하지 못하게 한다. 트루 분기의 추가 영업·사건·자유시간을 정확히 사용한 경우에만 전원 조건 완성이 가능하다.
- 관계 인물에게 N/R/SR/SSR 등급을 붙이지 않고 일반 손님 시장·금액·평판 계산과 분리한다.
- 핵심 보상은 감정적 장면, 관점, 사건 선택과 엔딩이다. 조사 신뢰와 개인 호감도의 일정 기준에서는 서로 다른 전시품 후보군과 최초 기념 제안을 열지만, 선택한 패시브는 현재 런에만 남고 연애 후보가 실무 협력 후보의 상위 호환이 되지 않는다.
- 각 우호·중립 종족도 우호도와 관련 사건 기준을 만족하면 종족 전시품 후보군과 최초 기념 제안을 연다. 반복 평판 수치만으로 지급하지 않는다.

## 8. 최종 운영 목표와 엔딩

- 일정 영업 안에 목표 금액, 채무 또는 상속 조건을 해결하는 것을 기본 승리 축으로 둔다.
- 투자와 최종 목표 자금 사이의 교환 관계를 유지한다.
- 안정 운영은 메인 스토리를 완주할 수 있지만 확인할 수 있는 관계와 진상은 제한된다.
- 종족·관계 엔딩도 기본 운영 목표를 달성한 경우에만 열린다.
- 구체적인 기한과 금액은 경로별 추가 영업이 경제를 자동으로 쉽게 만들지 않도록 별도 시뮬레이션한다.

### 엔딩 판정 계층

엔딩 후보는 동시에 여러 개가 성립할 수 있으므로 아래 순서에서 가장 구체적인 하나를 채택한다. 배드 엔딩 조건은 다른 모든 후보보다 먼저 운영 생존 여부를 검사한다.

| 우선 | 계층 | 회색 상자 기준 조건 |
| ---: | --- | --- |
| 1 | 배드 | 챕터 핵심 허들 회복 실패 또는 최종 자금·평판 목표 실패 |
| 2 | 트루 하렘 | 트루 조건과 5명 전원의 관계 엔딩 조건 완료 |
| 3 | 트루 | 악신의 증거와 전 종족 평화 협약 완료. 조건을 채운 관계 인물 중 한 명을 선택하거나 단독 결말 가능 |
| 4 | 종족 관계 인물 | 최고 우호도 종족의 전용 협약과 해당 관계 인물의 필수 사건 완료 |
| 5 | 종족 | 최고 우호도 종족이 임계치를 넘고 해당 종족 결말 협약 발동. 몽마는 타종족 우호 교류망도 필요 |
| 6 | 노말 | 호텔 생존 목표를 달성했지만 상위 분기 미충족 |

종족 우호도 동률은 자동으로 낮은 순번 종족을 고르지 않는다. 마지막 운영 방향 선언이 최고 우호도 집단 중 하나를 확정했을 때만 종족 엔딩으로 가며, 선언이나 전용 협약이 없으면 노말 엔딩으로 귀결한다.

챕터 허들은 `경고 실패 → 회복 영업·추가 채무·기회 손실`과 `회복까지 실패 → 배드 엔딩`을 구분한다. 모든 챕터의 첫 실패를 즉시 종료로 만들지 않는다. 세부 임계치와 회복 비용은 이후 경제 시뮬레이션에서 확정한다.

### 종족 엔딩에서 지배인의 종족 선택

플레이어는 인간 지배인으로 캠페인을 시작한다. 종족 엔딩의 후일담에서는 인간으로 남는 선택과 해당 종족의 삶에 들어가는 선택을 열 수 있으며, 캠페인 중간에 종족을 바꾸어 객실 규칙이나 운영 능력치를 얻는 성장 시스템으로 사용하지 않는다.

| 종족 | 지배인의 엔딩 선택 |
| --- | --- |
| 인족 | 인간 지배인으로 남아 두 세계의 중재자가 됨 |
| 뱀파이어 | 인간 유지 또는 합의된 전환으로 뱀파이어가 됨 |
| 늑대인간 | 인간 유지 또는 합의된 물림·의식으로 늑대인간이 됨 |
| 마녀 | 인간인 채 약초학·마법 전수 또는 마녀 각성. 여성 지배인은 현재 성별로 각성하고 남성 지배인은 여성의 몸으로 바뀐 뒤 각성 |
| 몽마 | 인간 유지 또는 특별한 의식을 통한 사후·미래의 몽마 전생 |

몽마는 동족끼리 정기를 순환시키는 것만으로 장기 생존할 수 없으므로 `몽마 최고 우호도`만으로 종족 엔딩을 열지 않는다. 타종족 중 일정 수가 별도 우호도 기준을 넘고 합의된 꿈·정기 교류망이 성립해야 한다. 회색 상자에서는 `타종족 우호도 3 이상인 종족 2개`를 임시 기준으로 검증하며, 숫자는 정식 경로 시뮬레이션 뒤 교체한다.

### 관계 인물 후일담

- 모든 엔딩에서 실제로 만났거나 개인 장면을 연 관계 인물만 후일담에 등장한다. 만나지 않은 인물과 숨은 인물의 존재를 누설하지 않는다.
- 호텔 실패가 모든 인물의 삶을 붕괴시키지는 않는다. 독립적인 손님은 자기 삶으로 돌아가고, 호텔과 추진하던 협약·조사·거처에 실제로 의존한 부분만 영향을 받는다.
- 개인 사건에서 이미 얻은 성장은 배드 엔딩이라는 이유로 소급 취소하지 않는다. 미해결 문제는 해당 인물 사건의 인과에 따라 남는다.
- 관계 인물 엔딩은 해당 인물이 자기 종족과 삶을 버리고 직원이 되는 결말로 고정하지 않는다. 종족 대표, 외부 협력자, 공동 운영자 또는 동반자로서 호텔을 오갈 수 있다.

## 9. 무한 영업

플레이어 노출 명칭은 `무한 영업`으로 사용한다. `데스매치`는 내부 설계 설명에만 사용할 수 있다.

### 시즌 루프

1. 시즌 시작 시 영업 횟수와 다음 감사 목표를 공개한다.
2. 시드 기반 손님을 수용·거절하고 객실을 배정한다.
3. 영업 사이 시설·아이템·증축·계약 중 제한된 선택을 한다.
4. 시즌 종료 시 최근 운영 성과로 감사 평판을 계산한다.
5. 목표 이상이면 다음 위험 단계와 보상 풀을 연다.
6. 목표 미달이면 호텔 폐업으로 런을 종료하고 기록을 남긴다.

초기 시즌 길이는 v2와 연결하기 쉬운 5영업을 표본으로 검증하되 확정값으로 고정하지 않는다.

### 두 평판

- `런 명성`: 전체 런에 누적되며 손님·시설·아이템·계약 풀을 확장한다.
- `감사 평판`: 최근 시즌의 만족, 거절, 취소와 사고를 계산해 생존을 판정한다.

누적 명성만으로 생존을 판정하지 않는다. 초반 성공을 무기한 비축하거나 초반 실패가 영구 회복 불가능해지는 것을 막기 위해 감사 평판은 시즌마다 초기화하거나 제한적으로만 이월한다.

감사 목표는 시즌 시작 전에 공개하고 현재 속도로 도달 가능한지 표시한다. 종료는 가혹할 수 있지만 숨은 기준이나 사후 변경으로 발생해서는 안 된다.

## 10. 모드 간 상태 경계

두 모드는 운영 수첩 프로필을 공유하며, 여기에는 전시품의 후보군 자격과 제안·획득·발동 도감이 포함된다.

시드는 각기 다른 가능 세계를 가리킨다. 캠페인 세이브는 지배인과 호텔의 한 세계선을 보존하고, 무한 영업 시드는 별도 런을 만든다. 현실과 예지의 세계관적 해석은 시나리오 캠페인의 비서 장면에만 적용한다. 무한 영업의 `이번 영업 다시`는 체크포인트를 복원하는 기능적 편의이며 서사 사건이나 설정 단서로 취급하지 않는다. 캠페인의 장기 복귀점은 챕터 시작 하나, 단기 복귀점은 현재 영업 시작 하나로 제한하며 챕터 내부 여러 영업을 임의로 골라 되돌리지 않는다.

### 공유

- 확인한 호텔 규정과 종족·직업 정보
- 시설·아이템의 존재와 효과
- 발견한 숨은 선호와 시너지 변화형
- 손님 조우·투숙 기록
- 업적, 장식, 칭호와 최고 기록
- 전시품 후보군 자격과 제안·획득·발동 기록

### 분리

- 골드와 호텔·종족 평판
- 실제 소유 시설·아이템, 현재 런의 전시품 조합과 증축 상태
- 종족 협약과 현재 시너지 변화형
- 관계 인물 조사 신뢰·개인 호감도와 선택한 성별 변형
- 시나리오 플래그, 조사 증거와 엔딩 상태

캠페인에서 해금한 종족·시설 변형은 무한 영업의 생성 풀을 확장할 수 있다. 무한 영업에서 발견한 일반 손님 선호와 시설 사용 기록은 캠페인 수첩에서도 열람할 수 있다. 전시품 후보군 자격은 무한 영업의 제안 풀을 넓힐 수 있지만 이전 런의 실제 전시품과 패시브를 가져오지는 않는다. 새 런은 열린 풀에서 다시 무작위 후보를 선택한다.

- 화합 선택은 연합 신뢰와 증거 확보 비용을 낮추지만 중반 운영 난도를 높인다.
- 전문화 선택이 있어도 진입은 가능하되 늦은 화해·재건·추가 조사 비용을 요구한다.
- 숨은 조사 챕터는 예약 원본 비교, 단서와 보안 시설을 학습시킨다.
- 숨은 결전 챕터는 전 종족 시설·상극·시너지, 침투 위험과 대규모 평판 공격을 결합한다.
- 숨은 분기 해금은 한 번 성립하면 유지한다. 이후 평판 손실은 성공을 어렵게 하지만 이미 발견한 정체를 다시 숨기지 않는다.
- 관련 운영 수첩 항목은 발견 전에는 빈 슬롯, 총개수와 미발견 힌트도 표시하지 않는다.

## 12. 공정성과 검증 조건

- 경로별 추가 영업이 누적 평판과 골드를 자동으로 유리하게 만들지 않아야 한다.
- 종족 평판과 연합 조건은 개별 최대치가 아니라 전체 경로 시뮬레이션으로 검산한다.
- 종족 특수 영업은 대화만 있는 가짜 스테이지가 아니며 실제 운영 규칙을 가르치거나 시험한다.
- 사건 장면은 영업 제한 시간 중 강제로 재생하지 않는다.
- 선택 전에 시설·시너지·하드 제약의 운영 방향을 보여주되 숨은 엔딩 점수는 노출하지 않는다.
- 기본 엔딩, 관계 엔딩과 최고난도 경로가 각각 독립적으로 완결되어야 한다.
- 무한 영업의 감사 목표는 해당 시즌 상태에서 수학적으로 도달 가능해야 한다.
