# UI 흐름과 회색 상자 와이어프레임

- 상태: READY FOR PROTOTYPE
- 대상: 데스크톱 브라우저, 1280×720 기준
- 입력: 마우스 우선, 클릭 대체 조작 제공

## 1. 화면 흐름

```text
[시작]
   ↓
[첫 영업 안내]
   ↓
[첫 객실 배치]
   ↓ 마감 가능
[첫 영업 결과/수입]
   ↓
[시설 제안 3개]
   ↓ 구매
[두 번째 예약: 수용/거절]
   ↓ 명단 확정
[두 번째 객실 배치]
   ↓ 마감 가능
[최종 평가]
   ├─ 다시 하기 → [시작]
   └─ 같은 시설로 재도전 → [두 번째 예약]
```

브라우저 뒤로 가기에 의존하지 않는다. 게임 내부 상태 전환만 사용한다.

## 2. 공통 화면 구조

```text
┌──────────────────────────────────────────────────────────────┐
│ 호텔명 / 오늘 단계                  골드  평판  응대 4/5     │
├───────────────────────────────────────────┬──────────────────┤
│                                           │ 선택한 손님/시설 │
│              주요 작업 영역              │ 조건 상세        │
│                                           │ 점수 구성        │
│                                           │ 충돌 원인        │
├───────────────────────────────────────────┴──────────────────┤
│ 단계 안내 / 경고                         [주요 행동 버튼]   │
└──────────────────────────────────────────────────────────────┘
```

- 상단: 변하지 않는 자원과 현재 단계
- 중앙 왼쪽: 예약 카드 또는 객실 보드
- 중앙 오른쪽: 선택한 항목의 상세 정보
- 하단: 지금 해야 할 행동과 진행 버튼

## 3. 시작 화면

### 표시

- 임시 제목
- 초대장 본문: `손님마다 필요한 숙박 조건을 확인하고, 제한된 객실 안에서 가장 만족스러운 투숙을 준비해 주십시오.`
- 핵심 조작 세 줄
- `영업 시작` 버튼

### 제외

- 설정 메뉴
- 세이브 불러오기
- 크레딧
- 복잡한 세계관 설명

## 4. 예약 화면

```text
┌────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐
│ Morrow     │ │ Fen        │ │ Lady Nox   │ │ Garr       │
│ 일반       │ │ 일반       │ │ 귀빈       │ │ 귀빈       │
│ 숙박비 6   │ │ 숙박비 5   │ │ 숙박비 15  │ │ 숙박비 14  │
│ 공통 필수  │ │ 공통 필수  │ │ 공통 필수  │ │ 공통 필수  │
│ 거절 -1    │ │ 거절 -1    │ │ 거절 -4    │ │ 거절 -4    │
│ [수용]     │ │ [수용]     │ │ [수용]     │ │ [수용]     │
└────────────┘ └────────────┘ └────────────┘ └────────────┘

응대 가능: 2/3 추가 손님
예상 거절 손실: -4                         [명단 확정]
```

### 규칙

- 카드를 클릭하면 우측에 종족·등급 표식, 개인 선호, 손익만 표시
- 종족·등급 공통 규칙은 상단의 `운영 수첩`에서 언제든 다시 확인
- `수용`과 `거절`은 한 번 더 클릭해 전환
- 응대 한도 초과 시 명단 확정 비활성화
- 미결정 손님이 있으면 확정 불가
- 거절 선택은 붉은색만으로 표현하지 않고 `거절됨` 텍스트와 아이콘 병행
- 귀빈은 왕관 아이콘과 굵은 테두리로 등급 구분

## 5. 객실 배치 화면

```text
┌──────────── 호텔 객실 ────────────┐  ┌──── 대기 손님 ────┐
│ F3  [A:소음] [B:조용] [C:햇빛]  │  │ Lune             │
│ F2  [A:소음] [B:조용] [C:햇빛]  │  │ Morrow           │
│ F1  [A:소음] [B:조용] [C:햇빛]  │  │ Aru              │
└───────────────────────────────────┘  │ Fen              │
                                       └───────────────────┘

배정 불가: 1건     만족 점수: 12/18     [밤 마감]
```

### 배치 조작

- 손님 카드를 객실로 드래그해 배치
- 클릭 대체: 손님 클릭 → 객실 클릭
- 점유 객실에 새 손님을 놓으면 두 손님 위치 맞바꾸기
- 배치된 손님을 대기 영역으로 돌릴 수 있음
- 모든 수용 손님이 배치되지 않으면 마감 불가

### 객실 표현

- 객실 좌표
- 속성 아이콘과 텍스트
- 배치된 손님 초상 대체 원형과 이름
- 시설이 바꾼 속성은 시설 아이콘과 변경 전/후 툴팁 표시
- 비밀 통로는 두 객실 사이를 점선으로 연결

### 필수 조건 피드백

- 위반 손님과 원인을 굵은 선으로 연결
- 우측 상세에 한 문장 원인 표시
- 필수 조건 미충족 수를 하단에 표시
- 붉은색 외에 `!` 아이콘과 선 형태 사용

### 점수 피드백

- 배치 직후 총점 갱신
- 손님 카드에 현재 얻은 점수 표시
- 우측 상세에 충족한 선호와 놓친 선호 구분
- 최고점은 처음부터 공개하지 않고 `?`로 표시 가능
- 첫 영업을 한 번 완료한 뒤 해당 문제의 최고점 공개

## 6. 영업 결과 화면

### 표시 순서

1. 영업 성공
2. 손님별 만족 점수
3. 기본 숙박비
4. 팁
5. 평판 변화
6. 총수입
7. 영업 평가와 등급

```text
만족 점수       18
평판 변화       +4
기본 숙박비     23G
팁              18G
총수입          41G
영업 평가       35  최고의 배치
```

각 숫자는 클릭하면 출처를 펼쳐볼 수 있게 한다.

## 7. 시설 선택 화면

- 카드 3개를 가로로 표시
- 가격, 공개 효과, 바뀌는 객실과 관계를 미리보기로 표시
- 구매 불가 시설은 잠그되 필요한 골드 차이를 표시
- 선택 전 현재 호텔 보드 위에 예상 변화를 미리 표시
- 구매 후 되돌리기는 프로토타입에서 허용하지 않음

시설 카드:

- 방음 객실 25G
- 라운지 30G
- 비밀 통로 35G

## 8. 최종 평가 화면

- 첫 영업과 두 번째 영업 비교
- 선택한 시설
- 수용 및 거절 손님
- 총수입
- 총 평판 변화
- 두 번째 영업 최고점 대비 결과
- `처음부터 다시`와 `두 번째 영업 재도전` 버튼

## 9. 텍스트 원칙

- 전문 용어 금지
- 조건은 한 문장, 24자 안팎을 목표
- 필수 조건 문장은 필요한 객실 상태를 긍정형으로 먼저 표시하고, 미충족 사유는 `배정할 수 없습니다`로 끝냄
- 선호 사항 문장은 `좋아합니다 +N`으로 끝냄
- 결과 설명은 행동과 원인을 모두 포함

예:

- `뱀파이어는 햇빛 객실에 머물 수 없습니다.`
- `Fen은 Aru의 옆방에 있어야 합니다.`
- `Garr는 라운지 옆을 좋아합니다. +5`
- `비밀 통로 때문에 F1-B와 F3-C는 이웃입니다.`

## 10. 반응형 최소 기준

- 1280×720: 기준 레이아웃
- 1024×576: 정보 패널 폭 축소
- 800px 미만: 프로토타입에서는 지원하지 않고 안내 표시
- 브라우저 확대 125%에서도 주요 버튼 접근 가능
