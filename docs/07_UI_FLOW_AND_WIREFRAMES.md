# UI 흐름과 회색 상자 와이어프레임

- 상태: `v2 IMPLEMENTED / TERMINOLOGY UPDATED`
- 대상: 데스크톱 브라우저, 1280×720 기준
- 입력: 마우스 우선, 클릭은 손님 정보 열람, 드래그 앤 드롭은 객실 배정

## v2 권위 화면 흐름

```text
[베스페라 호텔 초대장]
   ↓
[시간 제한 없는 객실 배정 연습] ── 건너뛰기 ─┐
   ↓ 완료                                      │
   └───────────────────────────────────────────┘
   ↓
[1회차 영업: N 고정 명단]
   ↓ 결산·객실 마모·숨은 선호 열람
[영업 준비 / 공사 계약]
   ├─ 동관 증축: 최대 1건
   └─ 시설·인테리어: 최대 1건
   ↓ 정비와 계약을 마치고 다음 영업
[2~5회차 예약 신청: 수용/거절]
   ↓
[연박 고정 객실 + 신규 손님 객실 배정]
   ↓
[영업 결산] → 다음 회차의 영업 준비
   ↓ 5회차 완료
[쇼케이스 종합 결과]
```

`영업 준비 / 공사 계약`은 한 화면에서 객실 정비와 두 계약 분류를 비교한다. 각 영업 사이 `동관 증축`과 `시설·인테리어`에서 각각 최대 1건만 계약할 수 있으며, 아무것도 사지 않고 다음 영업으로 갈 수도 있다. 시설은 교체 슬롯이 아니라 누적 보유한다. 동관은 `F1-D → F2-D → F3-D` 순서로만 계약 가능하다.

연박 중인 객실을 막거나 해당 객실의 속성·동선·보너스를 바꾸는 인테리어 카드에는 `연박 객실은 공사 불가`를 표시하고 계약 버튼을 잠근다.

### v2 정보 언어

- 플레이어 노출에서는 `퍼즐`, `CSP`, `hard/soft`를 쓰지 않고 `영업`, `객실 배정`, `필수 숙박 조건`, `선호`, `운영`, `공사 계약`으로 표현한다.
- 내부의 `압축 쇼케이스`는 플레이 화면에서 `개장 전 초청 영업`으로 표현한다. 압축 범위 설명은 제출 영상 초반의 단일 고지로 분리한다.
- 아직 만나지 않은 종족·등급의 공개 규정은 `미열람 규칙`이다. 첫 신청이 도착하면 규정을 읽을 수 있고 등급 규정은 자동 열람된다.
- 손님 카드에는 종족, N/R/SR/SSR 태그, 숙박 일수, 공개 개인 선호, 숙박비·거절 손실, 객실 영향을 표시한다.
- 종족×등급의 `숨은 선호`는 결산 뒤 열람하며 언제나 양수 점수의 선택 사항이다.
- 5회차 SSR은 세계관 안의 `왕실 특별 초청`으로 표시한다. 압축 시연 범위는 영상 초반에 한 번만 설명하고 카드·결산에서 반복하지 않는다.

### v2 객실 배정 피드백

- 연박 손님과 객실에는 `연박 고정` 표식을 붙이고 이동·맞바꾸기를 비활성화한다.
- 객실에 청결·내구 상태와 정비 필요 여부를 함께 표시한다.
- 같은 종족 인원 시너지와 같은 층 상극은 별도 효과 띠로 원인을 보여 준다.
- 현재 만족도 합계만 표시하고 검산된 최대 만족도는 공개하지 않는다.
- SR/SSR의 빈 이웃 객실 요청은 `사생활 선호 +N`으로 표시하며 배정 불가 사유로 표현하지 않는다.

## v1 보존 기록 — 최초 2영업 UI

아래 화면 흐름과 수치는 2영업 v1의 제작·영상 기록이다. 현재 v2의 영업 수, 등급, 공사 계약 UI 권위 기준으로 사용하지 않는다.

## 1. 화면 흐름

```text
[시작]
   ↓
[시간 제한 없는 배치 연습] ── 건너뛰기 ─┐
   ↓ 풀이 완료                            │
   └──────────────────────────────────────┘
   ↓
[첫 객실 배치]
   ↓ 마감 가능
[첫 영업 결과/수입]
   ↓
[시설 제안 3개]
   ↓ 구매
[두 번째 예약: 수용/거절]
   ↓ 명단 확정
[두 번째 객실 배치]
   ↓ 마감 가능
[최종 평가]
   ├─ 다시 하기 → [시작]
   └─ 같은 시설로 재도전 → [두 번째 예약]
```

브라우저 뒤로 가기에 의존하지 않는다. 게임 내부 상태 전환만 사용한다.

## 2. 공통 화면 구조

```text
┌──────────────────────────────────────────────────────────────┐
│ 호텔명 / 오늘 단계                  골드  평판  응대 4/5     │
├───────────────────────────────────────────┬──────────────────┤
│                                           │ 선택한 손님/시설 │
│              주요 작업 영역              │ 조건 상세        │
│                                           │ 점수 구성        │
│                                           │ 충돌 원인        │
├───────────────────────────────────────────┴──────────────────┤
│ 단계 안내 / 경고                         [주요 행동 버튼]   │
└──────────────────────────────────────────────────────────────┘
```

- 상단: 변하지 않는 자원과 현재 단계
- 중앙 왼쪽: 예약 카드 또는 객실 보드
- 중앙 오른쪽: 선택한 항목의 상세 정보
- 하단: 지금 해야 할 행동과 진행 버튼

## 3. 시작 화면

### 표시

- 임시 제목
- 초대장 본문: `손님마다 필요한 숙박 조건을 확인하고, 제한된 객실 안에서 가장 만족스러운 투숙을 준비해 주십시오.`
- 핵심 조작 세 줄
- `배치 연습 시작`과 `튜토리얼 건너뛰기` 버튼

### 제외

- 설정 메뉴
- 세이브 불러오기
- 크레딧
- 복잡한 세계관 설명

## 4. 예약 화면

```text
┌────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐
│ Morrow     │ │ Fen        │ │ Lady Nox   │ │ Garr       │
│ N          │ │ N          │ │ SR         │ │ SR         │
│ 숙박비 6   │ │ 숙박비 5   │ │ 숙박비 15  │ │ 숙박비 14  │
│ 공통 필수  │ │ 공통 필수  │ │ 공통 필수  │ │ 공통 필수  │
│ 거절 -1    │ │ 거절 -1    │ │ 거절 -4    │ │ 거절 -4    │
│ [수용]     │ │ [수용]     │ │ [수용]     │ │ [수용]     │
└────────────┘ └────────────┘ └────────────┘ └────────────┘

응대 5/6명 · 호텔 객실 10실 · 사용 가능 9실 · 배정 여유 4실
연박 고정: Garr F1-B                    [현재 객실도] [명단 확정]
```

### 규칙

- 카드를 클릭하면 우측에 종족·등급 표식, 개인 선호, 손익만 표시
- 종족·등급 공통 규칙은 상단의 `운영 수첩`에서 언제든 다시 확인
- `수용`과 `거절`은 한 번 더 클릭해 전환
- 응대 한도는 기본 5명에서 완공된 동관 객실마다 1명씩 증가
- 응대 한도와 사용 가능 객실 수를 별도 표시하고, 둘 중 하나를 초과하면 명단 확정 비활성화
- 사전 확정 손님과 연박 손님을 분리해 표시하고 `현재 객실도`에서 연박 고정·사용 불가·미증축·빈 객실을 확인
- 두 인원 수치가 남아도 필수 숙박 조건의 조합 가능성은 보장하지 않는다는 위험 문구 표시
- 미결정 손님이 있으면 확정 불가
- 거절 선택은 붉은색만으로 표현하지 않고 `거절됨` 텍스트와 아이콘 병행
- N/R/SR/SSR은 회색·청색·보라색·금색과 서로 다른 기호·테두리로 함께 구분

## 5. 객실 배치 화면

```text
┌──────────── 호텔 객실 ────────────┐  ┌──── 대기 손님 ────┐
│ F3  [A:소음] [B:조용] [C:햇빛]  │  │ Lune             │
│ F2  [A:소음] [B:조용] [C:햇빛]  │  │ Morrow           │
│ F1  [A:소음] [B:조용] [C:햇빛]  │  │ Aru              │
└───────────────────────────────────┘  │ Fen              │
                                       └───────────────────┘

배정 불가: 1건     만족도 합계: 12     [밤 마감]
```

### 마감 시간

- 연습 화면은 `시간 제한 없음`과 연습 건너뛰기를 표시
- 실제 영업은 우측 상단에 `02:00`부터 감소하는 체크인 마감 표시
- 남은 30초와 10초에 색과 명도를 단계적으로 강화
- 객실 변경 횟수와 `회당 -5초`를 타이머 아래에 함께 표시
- 운영 수첩이 열려 있는 동안 타이머 일시정지
- 마감 후 결과 화면에 자동 배정 손님과 수용 후 강제 취소 손님 표시

### 배치 조작

- 손님 카드를 객실로 드래그해 배치
- 손님 카드를 클릭하면 배치를 바꾸지 않고 상세 정보만 열람
- 점유 객실에 새 손님을 놓으면 두 손님 위치 맞바꾸기
- 배치된 손님을 대기 영역으로 드래그해 배정 해제
- 모든 수용 손님이 배치되지 않으면 마감 불가
- 첫 배치는 무료이며, 이미 놓은 손님의 이동·회수·맞바꾸기는 5초 차감

### 객실 표현

- 객실 좌표
- 속성 아이콘과 텍스트
- 배치된 손님 초상 대체 원형과 이름
- 시설이 바꾼 속성은 시설 아이콘과 변경 전/후 툴팁 표시
- 비밀 통로는 두 객실 사이를 점선으로 연결

### 필수 조건 피드백

- 위반 손님과 원인을 굵은 선으로 연결
- 우측 상세에 한 문장 원인 표시
- 필수 조건 미충족 수를 하단에 표시
- 붉은색 외에 `!` 아이콘과 선 형태 사용

### 점수 피드백

- 배치 직후 총점 갱신
- 손님 카드에 현재 얻은 점수 표시
- 우측 상세에 충족한 선호와 놓친 선호 구분
- 최대 만족도는 플레이 UI에서 공개하지 않는다.
- 검산된 최대값은 퍼즐 검증과 밸런싱 자료에만 사용한다.

## 6. 영업 결과 화면

### 표시 순서

1. 영업 성공
2. 손님별 만족 점수
3. 기본 숙박비
4. 팁
5. 평판 변화
6. 총수입
7. 영업 평가와 등급

```text
만족도 합계     18
평판 변화       +4
기본 숙박비     23G
팁              18G
총수입          41G
영업 평가       35  훌륭한 운영
```

각 숫자는 클릭하면 출처를 펼쳐볼 수 있게 한다.

## 7. 시설 선택 화면

- 카드 3개를 가로로 표시
- 가격, 공개 효과, 바뀌는 객실과 관계를 미리보기로 표시
- 구매 불가 시설은 잠그되 필요한 골드 차이를 표시
- 선택 전 현재 호텔 보드 위에 예상 변화를 미리 표시
- 구매 후 되돌리기는 프로토타입에서 허용하지 않음

시설 카드:

- 방음 객실 25G
- 라운지 30G
- 비밀 통로 35G

## 8. 최종 평가 화면

- 첫 영업과 두 번째 영업 비교
- 선택한 시설
- 수용 및 거절 손님
- 총수입
- 총 평판 변화
- 두 번째 영업의 현재 평가 결과
- `처음부터 다시`와 `두 번째 영업 재도전` 버튼

## 9. 텍스트 원칙

- 전문 용어 금지
- 조건은 한 문장, 24자 안팎을 목표
- 필수 조건 문장은 필요한 객실 상태를 긍정형으로 먼저 표시하고, 미충족 사유는 `배정할 수 없습니다`로 끝냄
- 선호 사항 문장은 `좋아합니다 +N`으로 끝냄
- 결과 설명은 행동과 원인을 모두 포함

예:

- `뱀파이어는 햇빛 객실에 머물 수 없습니다.`
- `Fen은 Aru의 옆방을 선호합니다. +4`
- `Garr는 라운지 옆을 좋아합니다. +5`
- `비밀 통로 때문에 F1-B와 F3-C는 이웃입니다.`

## 10. 반응형 최소 기준

- 1280×720: 기준 레이아웃
- 1024×576: 정보 패널 폭 축소
- 800px 미만: 프로토타입에서는 지원하지 않고 안내 표시
- 브라우저 확대 125%에서도 주요 버튼 접근 가능
