# 세로 단면 구현 결과

- 상태: INTERNAL PASS
- 대상: 정적 웹 프로토타입
- 기준 해상도: 1280×720

## 구현된 한 세션

1. 첫 영업 손님 4명 배치
2. 종족·등급 공통 조건과 개인 선호 점수 실시간 확인
3. 첫 영업 수입·평판·평가 정산
4. 방음 객실·라운지·비밀 통로 중 하나 구매
5. 신청 손님 4명을 수용 또는 거절해 정원 5명 구성
6. 시설 효과가 반영된 두 번째 영업 배치
7. 최종 수입·평판·평가 확인 및 재시작

모든 화면의 상단에서 운영 수첩을 열 수 있다. 수첩은 호텔 공통 규정, 종족별 숙박 조건, 등급별 응대 규정, 발견·해금 기록을 분리하며 귀빈 규정은 첫 예약 등장 전까지 잠긴다. 손님 카드에는 종족·등급·개인 선호만 남긴다.

## 내부 검증 결과

| 경로 | 최고 선호 | 영업 수입 | 평판 변화 | 최종 평가 | 브라우저 |
|---|---:|---:|---:|---:|---|
| 첫 영업 | 19 | 42 | +4 | 35 | PASS |
| 방음 객실 | 26 | 73 | +10 | 60 | PASS |
| 라운지 | 28 | 75 | +10 | 63 | PASS |
| 비밀 통로 | 28 | 74 | +10 | 62 | PASS |

Python 검산기는 모든 유효 배치를 열거하고, Edge 자동 플레이는 각 시설의 대표 최고점 경로를 실제 UI 조작으로 재현한다. 콘솔 오류와 진행 차단은 발견되지 않았다.

배포 ZIP은 별도 임시 폴더에 압축 해제한 뒤 다시 정적 서버로 제공해 비밀 통로 경로 62점까지 통과했다. ZIP 루트에는 `index.html`, `styles.css`, `src/`, `data/`만 포함한다.

## 의도적으로 제외한 것

- 무작위 시설 상점
- 숨은 성향 발견과 수첩
- 종족별 평판과 특화 보상
- 증축·철거·객실 형태 변경
- 챕터, 실패, 영구 해금
- 저장과 불러오기
- 완성 아트·사운드

이 항목들은 코어 플레이테스트가 PASS일 때 확장한다. 이번 프로토타입은 시설 선택이 해법을 바꾸는지, 수용·거절과 배치 최적화가 하나의 판단으로 이어지는지만 검증한다.

## 남은 게이트

- 신규 플레이어 3명이 설명 없이 전체 세션을 완료하는가
- 최고점이 아닌 첫 유효 해법 이후 자발적으로 재배치하는가
- 시설을 가격이 아니라 다음 퍼즐의 구조로 비교하는가
- 손님 거절을 단순한 등급 비교가 아닌 공간 판단으로 설명하는가

판정 기준은 `docs/09_TEST_PLAN.md`를 따른다.
